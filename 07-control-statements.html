Chapter 7: Control Statements in C

Learn how control statements allow a C program to make decisions, choose between alternatives and control the order in which statements execute.

  • Use nested if statements.
  • Use the else-if ladder.
  • Use switch statements.
  • Use break and continue where appropriate.
  • Choose suitable control statements for problems.
  • Write programs using conditional logic.

7.1 Introduction to Control Statements

Normally, a C program executes statements in sequence. Control statements allow the program to change that normal flow according to conditions or program requirements.

For example, a program can check whether a student has passed an examination and display a different message depending on the result. 

if (marks >= 40)
{
    printf("Pass");
}
Simple definition: Control statements determine the order in which statements are executed.

7.2 Historical Background

Control flow is a fundamental concept shared by most procedural programming languages. C provides a compact set of control statements that can express decisions, repetition and jumps.

The decision-making statements in C are especially useful for writing programs that respond differently to different input values.

In later chapters, loops will be studied in greater detail. This chapter focuses primarily on conditional and selection control statements.

7.4 if Statement

The if statement executes a block of code when its condition evaluates to true.

Syntax

if (condition)
{
    statements;
}

Example

#include <stdio.h>

int main()
{
    int age = 20;

    if (age >= 18)
    {
        printf("You are an adult.");
    }

    return 0;
}

Output

You are an adult.

7.6 if-else Statement

The if-else statement provides two alternatives. One block executes when the condition is true, and the other executes when it is false.

Syntax

if (condition)
{
    statements;
}
else
{
    statements;
}

Example

#include <stdio.h>

int main()
{
    int number = 10;

    if (number % 2 == 0)
    {
        printf("Even");
    }
    else
    {
        printf("Odd");
    }

    return 0;
}

Output

Even

7.8 Nested if Statement

An if statement placed inside another if statement is called a nested if.

Example

#include <stdio.h>

int main()
{
    int age = 20;
    int hasId = 1;

    if (age >= 18)
    {
        if (hasId)
        {
            printf("Entry allowed");
        }
    }

    return 0;
}

Output

Entry allowed
Deeply nested conditions can make code difficult to read. Use them only when the logic genuinely requires nesting.

7.9 else-if Ladder

An else-if ladder is useful when several conditions need to be checked in sequence.

Syntax

if (condition1)
{
    statements;
}
else if (condition2)
{
    statements;
}
else if (condition3)
{
    statements;
}
else
{
    statements;
}

Example

#include <stdio.h>

int main()
{
    int marks = 75;

    if (marks >= 90)
    {
        printf("Grade A+");
    }
    else if (marks >= 75)
    {
        printf("Grade A");
    }
    else if (marks >= 60)
    {
        printf("Grade B");
    }
    else if (marks >= 40)
    {
        printf("Grade C");
    }
    else
    {
        printf("Fail");
    }

    return 0;
}

Output

Grade A

7.11 switch Statement

The switch statement selects one of several statement blocks based on the value of an integer-like controlling expression.

Syntax

switch (expression)
{
    case constant1:
        statements;
        break;

    case constant2:
        statements;
        break;

    default:
        statements;
}

7.12 switch Example

#include <stdio.h>

int main()
{
    int day = 2;

    switch (day)
    {
        case 1:
            printf("Monday");
            break;

        case 2:
            printf("Tuesday");
            break;

        case 3:
            printf("Wednesday");
            break;

        default:
            printf("Invalid day");
    }

    return 0;
}

Output

Tuesday

7.14 break Statement

The break statement terminates the nearest enclosing loop or switch statement.

Example with switch

switch (choice)
{
    case 1:
        printf("One");
        break;

    case 2:
        printf("Two");
        break;
}

In a switch, break normally prevents execution from continuing into the next case.

7.15 switch Fall-Through

If a case does not contain a break, execution can continue into the following case. 

#include <stdio.h>

int main()
{
    int number = 1;

    switch (number)
    {
        case 1:
            printf("One\n");

        case 2:
            printf("Two\n");

        default:
            printf("End");
    }

    return 0;
}

Output

One
Two
End
Fall-through can be intentional, but accidental fall-through is a common source of bugs.

7.16 default Case

The default label is used when none of the listed case values match. 

switch (choice)
{
    case 1:
        printf("Add");
        break;

    case 2:
        printf("Exit");
        break;

    default:
        printf("Invalid choice");
}

The default case is optional, but it is often useful for handling unexpected values.
