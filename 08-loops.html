Chapter 8: Loops in C

Loops are used to execute a block of statements repeatedly. They are one of the most important concepts in C programming because they reduce code repetition and make programs more efficient and easier to understand.

Introduction to Loops

In programming, many tasks need to be performed repeatedly. For example, printing numbers from 1 to 100 would require many statements if loops were not available.

A loop allows a programmer to execute the same block of code multiple times based on a condition.

Without a Loop

printf("Hello\n");
printf("Hello\n");
printf("Hello\n");
printf("Hello\n");
printf("Hello\n");

With a Loop

for (int i = 1; i <= 5; i++)
{
    printf("Hello\n");
}
Simple Definition: A loop is a control structure that repeatedly executes a block of statements while a specified condition is true.

Why Are Loops Needed?

Loops are needed whenever the same operation has to be performed multiple times.

  • To reduce code repetition.
  • To make programs shorter.
  • To process large amounts of data.
  • To calculate mathematical values.
  • To process arrays.
  • To search data.
  • To generate patterns.
  • To display multiplication tables.
  • To repeatedly display menus.

while Loop

The while loop executes a block of statements as long as its condition remains true.

The condition is checked before the loop body executes. Therefore, while is an entry-controlled loop.

Syntax

while (condition)
{
    statements;
}

Example

#include <stdio.h>

int main()
{
    int i = 1;

    while (i <= 5)
    {
        printf("%d\n", i);
        i++;
    }

    return 0;
}

Output

1
2
3
4
5

do-while Loop

The do-while loop executes its body first and checks the condition after execution.

Therefore, the do-while loop executes at least once.

Syntax

do
{
    statements;
}
while (condition);
The semicolon after the while condition is required.

Example

#include <stdio.h>

int main()
{
    int i = 1;

    do
    {
        printf("%d\n", i);
        i++;
    }
    while (i <= 5);

    return 0;
}

Output

1
2
3
4
5

do-while Executes At Least Once

#include <stdio.h>

int main()
{
    int i = 10;

    do
    {
        printf("Executed once");
    }
    while (i < 5);

    return 0;
}

Output

Executed once
Even though the condition is false, the body executes once because the condition is checked after the body.

for Loop

The for loop is commonly used when initialization, condition and update can be written together.

Syntax

for (initialization; condition; update)
{
    statements;
}

Example

#include <stdio.h>

int main()
{
    for (int i = 1; i <= 5; i++)
    {
        printf("%d\n", i);
    }

    return 0;
}

Parts of a for Loop

for (int i = 1; i <= 10; i++)
Part Example Purpose
Initialization int i = 1 Sets the starting value.
Condition i <= 10 Controls whether another iteration occurs.
Update i++ Changes the loop variable.

Difference Between while, do-while and for

Feature while do-while for
Condition Before body After body Before body

Nested Loops

A loop placed inside another loop is called a nested loop.

The inner loop completes all of its iterations for every iteration of the outer loop.

Example

#include <stdio.h>

int main()
{
    for (int i = 1; i <= 3; i++)
    {
        for (int j = 1; j <= 3; j++)
        {
            printf("* ");
        }

        printf("\n");
    }

    return 0;
}

Output

* * *
* * *
* * *

break Statement

The break statement immediately terminates the nearest enclosing loop. 

#include <stdio.h>

int main()
{
    for (int i = 1; i <= 10; i++)
    {
        if (i == 6)
        {
            break;
        }

        printf("%d\n", i);
    }

    return 0;
}

Output

1
2
3
4
5

continue Statement

The continue statement skips the remaining statements in the current iteration and proceeds to the next iteration. 

#include <stdio.h>

int main()
{
    for (int i = 1; i <= 5; i++)
    {
        if (i == 3)
        {
            continue;
        }

        printf("%d\n", i);
    }

    return 0;
}

Output

1
2
4
5

Infinite Loop

An infinite loop is a loop that does not terminate because its condition never becomes false.

Example

while (1)
{
    printf("Running...\n");
}
Accidental infinite loops are usually programming errors. Always make sure that the loop has a way to terminate.

Loop Control Variable

A loop-control variable is a variable used to control the number of iterations of a loop. 

for (int i = 1; i <= 10; i++)
{
    printf("%d\n", i);
}

In this example, i is the loop-control variable.

Make sure the loop-control variable is initialized correctly and updated properly.

Program: Sum of First N Natural Numbers

#include <stdio.h>

int main()
{
    int n;
    int sum = 0;

    printf("Enter n: ");
    scanf("%d", &n);

    for (int i = 1; i <= n; i++)
    {
        sum += i;
    }

    printf("Sum = %d", sum);

    return 0;
}

Output

Enter n: 5
Sum = 15

Program: Factorial of a Number

#include <stdio.h>

int main()
{
    int n;
    unsigned long long factorial = 1;

    printf("Enter a number: ");
    scanf("%d", &n);

    if (n < 0)
    {
        printf("Factorial is not defined for negative integers.");
        return 0;
    }

    for (int i = 1; i <= n; i++)
    {
        factorial *= i;
    }

    printf("Factorial = %llu", factorial);

    return 0;
}

Output

Enter a number: 5
Factorial = 120

Program: Reverse a Number

#include <stdio.h>

int main()
{
    int number;
    int reverse = 0;
    int remainder;

    printf("Enter a number: ");
    scanf("%d", &number);

    while (number != 0)
    {
        remainder = number % 10;
        reverse = reverse * 10 + remainder;
        number /= 10;
    }

    printf("Reverse = %d", reverse);

    return 0;
}

Output

Enter a number: 12345
Reverse = 54321

Program: Check Palindrome Number

#include <stdio.h>

int main()
{
    int number;
    int original;
    int reverse = 0;
    int remainder;

    printf("Enter a number: ");
    scanf("%d", &number);

    original = number;

    while (number != 0)
    {
        remainder = number % 10;
        reverse = reverse * 10 + remainder;
        number /= 10;
    }

    if (original == reverse)
    {
        printf("Palindrome number");
    }
    else
    {
        printf("Not a palindrome number");
    }

    return 0;
}

Output

Enter a number: 121
Palindrome number

Program: Check Prime Number

#include <stdio.h>

int main()
{
    int number;
    int isPrime = 1;

    printf("Enter a number: ");
    scanf("%d", &number);

    if (number < 2)
    {
        isPrime = 0;
    }
    else
    {
        for (int i = 2; i * i <= number; i++)
        {
            if (number % i == 0)
            {
                isPrime = 0;
                break;
            }
        }
    }

    if (isPrime)
    {
        printf("Prime number");
    }
    else
    {
        printf("Not a prime number");
    }

    return 0;
}

Output

Enter a number: 17
Prime number

Program: Fibonacci Series

#include <stdio.h>

int main()
{
    int n;
    int first = 0;
    int second = 1;
    int next;

    printf("Enter number of terms: ");
    scanf("%d", &n);

    for (int i = 1; i <= n; i++)
    {
        printf("%d ", first);

        next = first + second;
        first = second;
        second = next;
    }

    return 0;
}

Output

Enter number of terms: 8
0 1 1 2 3 5 8 13

Common Errors in Loops

  • Forgetting to initialize the loop variable.
  • Forgetting to update the loop variable.
  • Using the wrong loop condition.
  • Creating an accidental infinite loop.
  • Using an incorrect starting value.
  • Using an incorrect ending value.
  • Using the wrong increment or decrement.
  • Incorrectly nesting loops.

Incorrect Example

int i = 1;

while (i <= 5)
{
    printf("%d", i);
}

The value of i never changes, so the condition always remains true.

Correct Example

int i = 1;

while (i <= 5)
{
    printf("%d", i);
    i++;
}

Best Practices for Loops

  • Initialize loop variables properly.
  • Use meaningful variable names.
  • Make sure the loop can terminate.
  • Keep loop conditions simple.
  • Avoid unnecessary nested loops.
  • Use break carefully.
  • Use continue carefully.
  • Check boundary conditions carefully.
  • Test loops with small values first.
Exam Tip: When explaining a for loop, remember the three important parts: initialization, condition and update.

Chapter Summary

Loops are control structures used to execute a block of statements repeatedly.

  • while: Checks the condition before executing the body.
  • do-while: Executes the body first and checks the condition afterward.
  • for: Commonly combines initialization, condition and update.
  • Nested loop: A loop inside another loop.
  • break: Terminates the nearest enclosing loop.
  • continue: Skips the remaining statements of the current iteration.
  • Infinite loop: A loop that does not terminate normally.
Key Point: Use a for loop when the number of iterations is known, a while loop when repetition depends on a condition, and a do-while loop when the body must execute at least once.
