Chapter 15: Enumerations in C

Learn how enumeration types allow programmers to define named integer constants that make C programs easier to understand, read and maintain.

15.1 Introduction to Enumerations

An enumeration, commonly called an enum, is a user-defined type in C that consists of a set of named integer constants.

Enumerations are useful when a variable should represent one value from a fixed collection of named choices.

Example

enum Day
{
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY,
    SUNDAY
};

Here, MONDAY, TUESDAY, WEDNESDAY and the other names are enumeration constants.

Simple Definition: An enumeration is a user-defined type that provides a set of named integer constants.

15.2 Why Are Enumerations Needed?

Enumerations make programs easier to understand when a variable can have only a limited set of meaningful choices.

Without enum

int day = 1;

The number 1 does not clearly tell the reader what it represents.

With enum

enum Day
{
    MONDAY,
    TUESDAY,
    WEDNESDAY
};

enum Day day = MONDAY;

The name MONDAY makes the meaning much clearer.

  • Improves program readability.
  • Makes code easier to understand.
  • Provides meaningful names for integer constants.
  • Helps represent a fixed set of choices.
  • Makes programs easier to maintain.

15.3 Syntax of Enumeration

The general syntax for defining an enumeration is: 

enum enum_name
{
    constant1,
    constant2,
    constant3
};

Example

enum Color
{
    RED,
    GREEN,
    BLUE
};

Color is the enumeration type and RED, GREEN and BLUE are enumeration constants.

15.4 Declaring an Enum Variable

After defining an enumeration type, variables of that type can be declared. 

enum Color
{
    RED,
    GREEN,
    BLUE
};

enum Color color;

The variable color can be assigned one of the enumeration constants. 

color = RED;

15.5 Simple Enumeration Program

#include <stdio.h>

enum Day
{
    MONDAY,
    TUESDAY,
    WEDNESDAY
};

int main()
{
    enum Day day;

    day = TUESDAY;

    printf("Day value = %d\n",
           day);

    return 0;
}

Output

Day value = 1

By default, enumeration constants begin with the value 0 and increase by one.

15.6 Default Values of enum Constants

If values are not explicitly assigned, the first enumeration constant normally has the value 0, and each following constant increases by one. 

enum Number
{
    ZERO,
    ONE,
    TWO,
    THREE
};
Constant Value
ZERO 0
ONE 1
TWO 2
THREE 3

15.7 Custom Values in enum

Enumeration constants can be assigned specific integer values. 

enum Status
{
    SUCCESS = 1,
    ERROR = 5,
    UNKNOWN = 10
};

Here, the programmer explicitly assigns values to the constants.

Constant Value

ERROR 5
UNKNOWN 10

15.8 Mixed enum Values

Some enumeration constants can have explicit values while subsequent constants continue from the previous value. 

enum Numbers
{
    A = 10,
    B,
    C,
    D = 20,
    E

15.10 Characteristics of enum

  • Enumerations are user-defined types.
  • The enum keyword is used to define them.
  • Enumeration constants are named integer constants.
  • Values can be assigned explicitly.
  • If values are omitted, they normally increase from the previous value.
  • Enumeration constants make code more readable.
  • They are useful for representing a fixed set of choices.

Multiple variables of the same enumeration type can be declared. 

enum Color
{
    RED,
    GREEN,
    BLUE
};

enum Color color1;

Each variable can store a value from the enumeration. 

color1 = RED;

15.13 enum with switch Statement

Enumerations work particularly well with switch statements because each named constant represents a possible choice.

Example

#include <stdio.h>

enum Day
{
    MONDAY,
    TUESDAY,
    WEDNESDAY
};

int main()
{
    enum Day day = TUESDAY;

    switch (day)
    {
        case MONDAY:
            printf("Monday");
            break;

        case TUESDAY:
            printf("Tuesday");
            break;

        case WEDNESDAY:
            printf("Wednesday");
            break;
    }

    return 0;
}

Output

Tuesday

15.14 enum with if Statement

An enumeration variable can also be compared with enumeration constants using conditional statements. 

#include <stdio.h>

enum Status
{
    OFF,
    ON
};

int main()
{
    enum Status status = ON;

    if (status == ON)
    {
        printf("System is ON");
    }
    else
    {
        printf("System is OFF");
    }

    return 0;
}

Output

System is ON

15.15 enum with Loops

Enumeration constants can be used in loops when the program needs to process a fixed sequence of named values. 

#include <stdio.h>

enum Day
{
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY
};

int main()
{
    enum Day day;

    for (day = MONDAY; day <= FRIDAY; day++)
    {
        printf("%d\n", day);
    }

    return 0;
}

Output

0
1
2
3
4
This works because the enumeration values in this example are consecutive integer values.

15.22 enum with User Input

#include <stdio.h>

enum Choice
{
    EXIT = 0,
    ADD = 1,
    DELETE = 2
};

int main()
{
    int input;
    enum Choice choice;

    printf("0. Exit\n");
    printf("1. Add\n");
    printf("2. Delete\n");

    printf("Enter choice: ");
    scanf("%d", &input);

    choice = (enum Choice)input;

    switch (choice)
    {
        case ADD:
            printf("Add selected");
            break;

        case DELETE:
            printf("Delete selected");
            break;

        case EXIT:
            printf("Exit selected");
            break;

        default:
            printf("Invalid choice");
    }

    return 0;
}

Example Output

0. Exit
1. Add
2. Delete
Enter choice: 1
Add selected
User input should be validated before treating it as one of the application's expected enumeration values.

The typedef keyword can be used to create a shorter name for an enumeration type.

shirtSize = LARGE;

Enumeration constants can be used in expressions wherever their integer values are appropriate.

{
    ONE = 1,
    TWO = 2,
    THREE = 3

int result;

result = TWO + THREE;

In this example, result receives the integer value 5.

Enumeration constants have integer values, but the exact representation and some type details are implementation dependent in C. 

enum Number
{
    ZERO,

    TWO

15.26 enum with Structure

An enumeration can be used as a member of a structure. This is useful for storing a category or state together with other information. 

#include <stdio.h>

enum Gender
{
    MALE,
    FEMALE,
    OTHER
};

struct Student
{
    char name[30];
    enum Gender gender;
};

int main()
{
    struct Student student =
    {
        "Ravi",
        MALE
    };

    printf("Name = %s\n",
           student.name);

    printf("Gender value = %d\n",
           student.gender);

    return 0;
}

Output

Name = Ravi
Gender value = 0

15.37 Advantages of Enumerations

Enumerations provide several benefits when programming with a fixed set of related values.

  • Improves readability: Named constants are easier to understand than unexplained numeric values.
  • Improves maintainability: Meaningful names make programs easier to modify.
  • Represents fixed choices: Enumerations are useful for states, categories and options.
  • Works well with switch: Enum values make selection statements easier to read.
  • Reduces magic numbers: Names such as ACTIVE and INACTIVE are clearer than arbitrary numbers.
  • Useful in large programs: Named states make complex programs easier to understand.

15.38 Disadvantages of Enumerations

  • Enumeration constants represent integer values, so they are not suitable for every kind of data.
  • The numerical representation of an enum type can be implementation-dependent.
  • Care is required when converting arbitrary integers into enum values.
  • Enumeration constants share the same identifier namespace as other ordinary identifiers, so names should be chosen carefully.
  • Unnamed numeric values can sometimes make debugging less clear.

15.42 Common Errors in Enumerations

Error 1: Forgetting the semicolon

enum Color
{
    RED,
    GREEN,
    BLUE
}   /* Wrong */

The declaration must end with a semicolon. 

enum Color
{
    RED,
    GREEN,
    BLUE
};

Error 2: Using an undeclared enum type

enum Color color;

color = RED;

The enumeration type containing RED must have been declared before it is used.

Error 3: Confusing enum constants with strings

enum Color
{
    RED,
    GREEN
};

RED is an integer enumeration constant. It is not the string "RED".

Error 4: Invalid assumptions about numeric values

Do not assume that enumeration constants always have particular values when explicit values have been assigned.

15.43 Best Practices for Using enum

  • Use meaningful names for enumeration constants.
  • Use uppercase names when following a project convention for constants.
  • Use an enum when a variable represents one of a fixed set of related choices.
  • Prefer enum names that clearly describe the domain.
  • Use switch when several enum values require different actions.
  • Validate external integer input before converting it to an enum value.
  • Avoid relying unnecessarily on the numeric values of enum constants.
  • Keep enumeration definitions organized and easy to find.

15.54 Interview Questions

1. What is an enumeration in C?

An enumeration is a user-defined type containing a set of named integer constants.

2. Which keyword is used for enumeration?

The enum keyword.

3. What is the default value of the first enum constant?

If no value is specified, it normally starts at 0.

4. Can enum constants have custom values?

Yes. Integer values can be assigned explicitly.

5. Why should enum be used?

It makes programs more readable and clearly represents a fixed set of related choices.

6. Can enum be used with switch?

Yes. Enum values are commonly used in switch statements.

7. Can enum be used inside a structure?

Yes. An enum type can be declared as a structure member.

8. What is the difference between enum and #define?

An enum defines a set of named constants as part of an enumeration type, whereas #define performs preprocessor substitution.

9. Can a pointer point to an enum variable?

Yes. A pointer can store the address of an enum variable.

10. Give real-world examples of enum.

Traffic lights, user roles, account states, order states, game states and days of the week are common examples.
