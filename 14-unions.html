Chapter 14: Unions in C

Learn how unions allow different members to share the same memory location and how unions are used for memory-efficient data representation in C programming.

14.1 Introduction to Unions

A union is a user-defined data type in C that allows different members to share the same memory location.

A union can contain members of different data types. However, all members use the same block of memory.

Because the members share memory, a union can be useful when only one member needs to hold a meaningful value at a time.

Simple Example

union Data
{
    int number;
    float decimal;
    char letter;
};
Simple Definition: A union is a user-defined data type in C in which all members share the same memory location.

14.2 Why Are Unions Needed?

Unions are useful when different types of information need to use the same memory area and only one of those values is needed at a particular time.

  • To save memory.
  • To represent alternative types of data.
  • To work with memory-sensitive applications.
  • To represent hardware-related data.
  • To implement certain low-level programming techniques.
  • To store different possible data representations in the same memory area.

14.3 Basic Structure of a Union

A union is declared using the union keyword.

Syntax

union UnionName
{
    dataType member1;
    dataType member2;
    dataType member3;
};

Example

union Data
{
    int number;
    float decimal;
    char letter;
};

Here, Data is the name of the union and number, decimal and letter are its members.

14.4 Declaring Union Variables

After defining a union, variables of that union type can be declared.

Example

union Data
{
    int number;
    float decimal;
    char letter;
};

union Data data1;

Here, data1 is a union variable.

Multiple Union Variables

union Data data1, data2, data3;

14.5 Accessing Union Members

The dot operator . is used to access a member of a union variable.

Example

union Data data;

data.number = 100;

printf("%d", data.number);

In this example, the member number is assigned a value and then accessed using the dot operator.

Remember: Use the dot operator . when accessing a member through a union variable.

14.6 Simple Union Program

#include <stdio.h>

union Data
{
    int number;
    float decimal;
    char letter;
};

int main()
{
    union Data data;

    data.number = 100;

    printf("Number = %d\n",
           data.number);

    return 0;
}

Output

Number = 100

14.7 Memory Allocation in a Union

The most important feature of a union is that all its members share the same memory location.

The amount of memory allocated for a union is generally sufficient to hold its largest member, subject to the implementation's alignment requirements.

Example

union Data
{
    int number;
    float decimal;
    char letter;
};
UNION MEMORY +---------------------------+ | | | Shared Memory | | | +---------------------------+ | | | | | | int float char number decimal letter Only one member's stored value should normally be treated as the active value at a time.

14.8 Size of a Union

The sizeof operator can be used to determine the size of a union.

Example

#include <stdio.h>

union Data
{
    int number;
    float decimal;
    char letter;
};

int main()
{
    printf("Size of union = %zu bytes",
           sizeof(union Data));

    return 0;
}

The exact size depends on the sizes and alignment requirements of the members on the target system.

Important: Unlike a structure, union members share storage rather than each receiving separate storage.

14.9 Union Initialization

A union can be initialized when the variable is declared. In a normal initializer, the first member is initialized unless a designated initializer is used.

Example

union Data
{
    int number;
    float decimal;
    char letter;
};

union Data data = {100};

In this example, the first member number is initialized with the value 100.

Designated Initialization

union Data data =
{
    .decimal = 25.5
};

The designated initializer explicitly selects the member that should be initialized.

14.10 Active Union Member

A union has one shared storage area. When a value is stored through one member, that member is the one whose stored value should normally be interpreted. 

union Data data;

data.number = 100;

printf("%d", data.number);

Here, number is the member being used to store and retrieve the value.

Do not assume that assigning one union member leaves the previous member's value unchanged. Writing one member can change the representation of the shared storage.

14.11 Example with Different Union Members

#include <stdio.h>

union Data
{
    int number;
    float decimal;
    char letter;
};

int main()
{
    union Data data;

    data.number = 100;

    printf("Integer = %d\n",
           data.number);

    data.decimal = 25.5;

    printf("Float = %.2f\n",
           data.decimal);

    data.letter = 'A';

    printf("Character = %c\n",
           data.letter);

    return 0;
}

Output

Integer = 100
Float = 25.50
Character = A

Each assignment uses the same shared memory area.

14.12 Union vs Structure: Basic Idea

Structures and unions are both user-defined data types in C, but their memory organization is different.

Feature Structure Union
Memory Members have separate storage, subject to padding Members share the same storage
Values Multiple members can hold values simultaneously Only one member's stored value should normally be treated as active
Size Usually based on combined member storage and padding Usually based on the largest member and alignment
Keyword struct union

14.13 Structure and Union Memory Diagram

Structure

struct Data { int number; float decimal; char letter; }; Memory: +------------+ | number | +------------+ | decimal | +------------+ | letter | +------------+ Members have separate storage.

Union

union Data { int number; float decimal; char letter; }; Memory: +----------------------+ | | | Shared Storage | | | +----------------------+ number decimal letter Members share storage.

14.14 Important Characteristics of Unions

  • A union is a user-defined data type.
  • It is declared using the union keyword.
  • Different members can have different data types.
  • All members share the same memory location.
  • The size of a union is generally related to its largest member and alignment requirements.
  • The dot operator is used to access members through a union variable.
  • A pointer to a union can be used with the arrow operator.
  • Unions can contain arrays, pointers and other suitable members.
  • Unions are useful when memory efficiency is important.

14.15 Union Pointer

A pointer can store the address of a union variable. A union pointer can be used to access and modify the members of the union.

Syntax

union Data data;

union Data *ptr;

ptr = &data;

When a pointer to a union is used, the arrow operator -> can be used to access its members.

Example

#include <stdio.h>

union Data
{
    int number;
    float decimal;
    char letter;
};

int main()
{
    union Data data;

    union Data *ptr = &data;

    ptr->number = 100;

    printf("Number = %d\n",
           ptr->number);

    return 0;
}

Output

Number = 100

14.16 Accessing Union Through Pointer

There are two common ways to access a union member when a pointer to the union is available. 

ptr->number

The arrow operator is the simpler and commonly used form.

The following expression is equivalent: 

(*ptr).number
Remember:

Union variable → use .
Union pointer → use ->

14.17 Array of Unions

An array can contain multiple union objects of the same union type.

Syntax

union Data data[5];

This creates an array containing five union objects.

Example

#include <stdio.h>

union Data
{
    int number;
    float decimal;
};

int main()
{
    union Data data[3];

    data[0].number = 10;
    data[1].number = 20;
    data[2].number = 30;

    printf("%d\n", data[0].number);
    printf("%d\n", data[1].number);
    printf("%d\n", data[2].number);

    return 0;
}

Output

10
20
30

Each array element has its own shared storage area. The members within each individual union element share that element's storage.

14.18 Array of Unions with Different Members

Different elements of an array of unions can use different members when the program keeps track of which member is currently meaningful for each element. 

#include <stdio.h>

union Data
{
    int number;
    float decimal;
};

int main()
{
    union Data data[2];

    data[0].number = 100;
    data[1].decimal = 25.5;

    printf("Integer = %d\n",
           data[0].number);

    printf("Float = %.2f\n",
           data[1].decimal);

    return 0;
}

Output

Integer = 100
Float = 25.50

14.19 Union Inside a Structure

A structure can contain a union as one of its members. This is useful when a record can contain one of several alternative types of data.

Example

#include <stdio.h>

union Value
{
    int number;
    float decimal;
};

struct Data
{
    int type;
    union Value value;
};

int main()
{
    struct Data data;

    data.type = 1;
    data.value.number = 100;

    printf("Type = %d\n",
           data.type);

    printf("Value = %d\n",
           data.value.number);

    return 0;
}

Output

Type = 1
Value = 100

14.20 Structure Containing a Union

A common design is to use a structure containing a union together with a separate member that identifies which union member is currently being used. 

struct Item
{
    int type;

    union
    {
        int number;
        float price;
        char grade;
    } value;
};
The type member can be used by the program to record which member of the union should be interpreted.

14.21 Tagged Union

A union combined with a separate tag or discriminator is commonly called a tagged union.

The tag tells the program which union member currently represents the stored value.

TAGGED UNION +-------------+ | type | +-------------+ | +---------+---------+ | | type = 1 type = 2 | | v v int number float price

Example

#include <stdio.h>

struct Data
{
    int type;

    union
    {
        int number;
        float decimal;
    } value;
};

int main()
{
    struct Data data;

    data.type = 1;
    data.value.number = 500;

    if (data.type == 1)
    {
        printf("Integer = %d",
               data.value.number);
    }

    return 0;
}

Output

Integer = 500

14.22 Anonymous Union

An anonymous union is a union declared without a tag name inside another structure or union.

Its members can be accessed directly through the containing object.

Example

#include <stdio.h>

struct Data
{
    int type;

    union
    {
        int number;
        float decimal;
    };
};

int main()
{
    struct Data data;

    data.type = 1;
    data.number = 100;

    printf("Type = %d\n",
           data.type);

    printf("Number = %d\n",
           data.number);

    return 0;
}

Output

Type = 1
Number = 100

Anonymous unions are supported by modern C standards and can make access to union members more convenient.

14.23 Nested Union

A union can contain another union as a member.

Example

union Inner
{
    int number;
    float decimal;
};

union Outer
{
    union Inner data;
    char letter;
};

The nested union member can be accessed using the dot operator more than once. 

union Outer value;

value.data.number = 100;

14.24 Union with Character Array

A union can contain a character array. Since all members share storage, the character array uses the same memory area as the other union members.

Example

#include <stdio.h>

union Data
{
    int number;
    char text[20];
};

int main()
{
    union Data data;

    data.number = 100;

    printf("Number = %d\n",
           data.number);

    return 0;
}

Output

Number = 100

If another member is subsequently written, the shared storage may be changed.

14.25 Union with Pointer Member

A union can contain pointer members just like other suitable data members.

Example

#include <stdio.h>

union Data
{
    int *numberPtr;
    float *decimalPtr;
};

int main()
{
    int number = 100;

    union Data data;

    data.numberPtr = &number;

    printf("Number = %d\n",
           *data.numberPtr);

    return 0;
}

Output

Number = 100
Always make sure a pointer member points to a valid object before dereferencing it.

14.26 Passing a Union to a Function

A union can be passed to a function by value just like other C objects.

Example

#include <stdio.h>

union Data
{
    int number;
    float decimal;
};

void display(union Data data)
{
    printf("Number = %d\n",
           data.number);
}

int main()
{
    union Data data;

    data.number = 100;

    display(data);

    return 0;
}

Output

Number = 100

The function receives a copy of the union object.

14.27 Passing a Union Pointer to a Function

A pointer to a union can be passed to a function when the function needs to access or modify the original union object.

Example

#include <stdio.h>

union Data
{
    int number;
    float decimal;
};

void update(union Data *data)
{
    data->number = 500;
}

int main()
{
    union Data data;

    data.number = 100;

    update(&data);

    printf("Number = %d\n",
           data.number);

    return 0;
}

Output

Number = 500

14.28 Returning a Union from a Function

A function can return a union value.

Example

#include <stdio.h>

union Data
{
    int number;
    float decimal;
};

union Data createData()
{
    union Data data;

    data.number = 100;

    return data;
}

int main()
{
    union Data data;

    data = createData();

    printf("Number = %d\n",
           data.number);

    return 0;
}

Output

Number = 100

14.29 Union Assignment

Two union objects of the same union type can be assigned using the assignment operator. 

union Data data1;
union Data data2;

data1.number = 100;

data2 = data1;

The value of the union object is copied to the other union object.

Example

#include <stdio.h>

union Data
{
    int number;
    float decimal;
};

int main()
{
    union Data data1;
    union Data data2;

    data1.number = 250;

    data2 = data1;

    printf("Data 2 = %d",
           data2.number);

    return 0;
}

Output

Data 2 = 250

14.30 Union and sizeof Operator

The sizeof operator can be applied to a union type or a union variable. 

sizeof(union Data)

It can also be applied to a union object: 

union Data data;

sizeof(data);

The result represents the number of bytes occupied by the union object according to the implementation.

Exam Point: The size of a union is generally determined by its largest member, together with any alignment requirements.

14.31 Union Memory Visualization

Consider the following union: 

union Data
{
    int number;
    float decimal;
    char letter;
};
SAME MEMORY AREA +--------------------------------+ | | | UNION STORAGE | | | +--------------------------------+ ↑ ↑ ↑ | | | number decimal letter Writing: data.number = 100; uses the shared storage. Later: data.decimal = 20.5; writes a new value into the same storage.
Do not treat an old member as though it automatically retains its previous value after another member is written.

14.32 Important Points About Union Members

  • All union members begin at the same storage location.
  • Only one shared storage area is allocated for the union.
  • Writing one member can affect the representation of another member.
  • A program should keep track of which member is intended to represent the current value.
  • A separate tag can be used when multiple possible member types are needed safely.
  • The size of a union is not generally the sum of the sizes of all its members.

14.33 Detailed Difference Between Structure and Union

Structures and unions are both user-defined data types in C. They can contain members of different data types, but their memory allocation and usage are different.

Feature Structure Union
Keyword struct union
Memory allocation Separate memory for members, subject to padding Shared memory for all members
Member values Multiple members can hold values simultaneously One member's stored value is normally treated as active
Size Usually based on combined member storage and padding Usually based on the largest member and alignment
Memory usage Generally higher Generally lower
Purpose Store a complete record Store one of several alternative representations
Member access Dot or arrow operator Dot or arrow operator

14.34 Memory Difference Example

Consider the following structure and union: 

struct Data
{
    int number;
    float decimal;
    char letter;
};

union Data
{
    int number;
    float decimal;
    char letter;
};

In the structure, each member has its own storage. In the union, all members share the same storage.

STRUCTURE +-------------+ | number | +-------------+ | decimal | +-------------+ | letter | +-------------+ Each member has separate storage. UNION +----------------------+ | | | Shared Storage | | | +----------------------+ All members use the same storage.

#include <stdio.h>

struct StructureData

union UnionData

The exact sizes depend on the implementation, including type sizes and alignment requirements.

14.36 typedef with Union

The typedef keyword can be used to create a shorter and more convenient name for a union type.

Without typedef

union Data
{
    int number;
    float decimal;
};

union Data data;

With typedef

typedef union
{
    int number;
    float decimal;
} Data;

Data data;

The second method allows the programmer to use Data directly as the type name.

14.42 Union in Embedded and System Programming

Unions can be useful in low-level and embedded programming when a program needs to represent the same storage in different ways.

  • Hardware-related data representation.
  • Memory-sensitive applications.
  • Protocol data representation.
  • Device configuration data.
  • Systems programming.
  • Alternative representations of a value.
Union-based low-level techniques require careful attention to the C standard, object representation, alignment and portability.

14.43 Union and Memory Efficiency

One of the main reasons for using a union is to avoid allocating separate storage for alternative values that do not need to exist simultaneously.

Without Union: +------------+ | Integer | +------------+ | Float | +------------+ | Character | +------------+ Separate storage is required. With Union: +----------------------+ | Shared Memory Area | +----------------------+ Members share storage.

This can reduce memory usage when the application needs only one alternative value at a time.

14.44 Union with enum

An enumeration can be used as a tag to identify which member of a union is currently meaningful. 

#include <stdio.h>

enum DataType
{
    INTEGER,
    DECIMAL,
    CHARACTER
};

union Data
{
    int number;
    float decimal;
    char letter;
};

struct Value
{
    enum DataType type;
    union Data data;
};

int main()
{
    struct Value value;

    value.type = INTEGER;
    value.data.number = 100;

    if (value.type == INTEGER)
    {
        printf("Integer = %d",
               value.data.number);
    }

    return 0;
}

Output

Integer = 100

14.46 Important Rules for Unions

  1. Use the union keyword to define a union.
  2. All members share the same storage.
  3. Use the dot operator with a union variable.
  4. Use the arrow operator with a pointer to a union.
  5. Be careful when switching between union members.
  6. Keep track of which member represents the current value.
  7. Use a tag or enumeration when multiple alternatives need to be identified explicitly.
  8. Use unions when shared storage is appropriate.

14.47 Common Uses of Unions

Application Purpose
Embedded Systems Represent alternative hardware data
Memory Optimization Share storage between alternatives
Device Drivers Represent device-related data
Communication Protocols Represent alternative data formats
System Programming Work with low-level data representations
Tagged Data Store one of several possible data types

14.48 Advantages of Unions

Unions provide several advantages when multiple alternative values need to share storage.

  • Memory Saving: All members share the same memory area.
  • Efficient Storage: Useful when only one member needs to be stored at a time.
  • Flexible Representation: The same memory can represent different types.
  • Useful in System Programming: Helpful in low-level and embedded applications.
  • Useful for Tagged Data: A tag can identify which union member is active.
  • Simple Syntax: Union declaration and member access are similar to structures.

14.49 Disadvantages of Unions

  • Only one member's stored value should normally be interpreted at a time.
  • Writing one member can change the representation of the shared storage.
  • Incorrect member interpretation can produce unexpected results.
  • Programs may need an additional tag to track the currently meaningful member.
  • Low-level union techniques can reduce portability if they depend on implementation-specific object representations.
  • Unions can be confusing for beginners because all members share memory.

14.50 Common Errors in Unions

1. Forgetting the semicolon

union Data
{
    int number;
    float decimal;
}   /* Error */

A semicolon must be placed after the closing brace. 

union Data
{
    int number;
    float decimal;
};

2. Using the wrong operator

Use . with a union variable: 

data.number

Use -> with a pointer to a union: 

ptr->number

3. Assuming all members retain independent values

Union members share storage. Writing one member can change the representation of the shared storage.

4. Reading the wrong member

A program should normally read the member that corresponds to the current stored representation.

5. Invalid pointer usage

A pointer to a union must point to a valid union object before it is dereferenced.

14.51 Best Practices for Using Unions

  • Use unions when alternative values genuinely need to share storage.
  • Keep track of which member represents the current value.
  • Use an enum or other tag when the active member needs explicit identification.
  • Use meaningful names for union members.
  • Use pointers carefully.
  • Avoid assuming that unrelated union members can always be interpreted interchangeably.
  • Consider portability when using low-level object representation techniques.
  • Document unusual union usage clearly.
Best Practice: If a union contains several possible data types, keep a separate tag that tells the program which member should be interpreted.

14.52 Program: Employee Data Using a Union

The following example demonstrates a record that can store either an integer ID or a floating-point salary in a shared union. 

#include <stdio.h>

struct Employee
{
    int type;

    union
    {
        int id;
        float salary;
    } data;
};

int main()
{
    struct Employee employee;

    employee.type = 1;
    employee.data.id = 101;

    printf("Employee ID = %d\n",
           employee.data.id);

    employee.type = 2;
    employee.data.salary = 45000.0;

    printf("Salary = %.2f\n",
           employee.data.salary);

    return 0;
}

Output

Employee ID = 101
Salary = 45000.00

14.53 Program: Menu-Based Union Example

#include <stdio.h>

union Data
{
    int number;
    float decimal;
    char letter;
};

int main()
{
    union Data data;
    int choice;

    printf("1. Integer\n");
    printf("2. Float\n");
    printf("3. Character\n");

    printf("Enter choice: ");
    scanf("%d", &choice);

    switch (choice)
    {
        case 1:

            printf("Enter integer: ");
            scanf("%d", &data.number);

            printf("Integer = %d",
                   data.number);

            break;

        case 2:

            printf("Enter float: ");
            scanf("%f", &data.decimal);

            printf("Float = %.2f",
                   data.decimal);

            break;

        case 3:

            printf("Enter character: ");
            scanf(" %c", &data.letter);

            printf("Character = %c",
                   data.letter);

            break;

        default:

            printf("Invalid choice");
    }

    return 0;
}

Example Output

1. Integer
2. Float
3. Character
Enter choice: 1
Enter integer: 250
Integer = 250

#include <stdio.h>

enum Type
{
    TYPE_INT,
    TYPE_FLOAT,
    TYPE_CHAR
};

struct Data
{
    enum Type type;

    union
    {
        int number;
        float decimal;
        char letter;
    } value;
};

void display(struct Data data)
{
    switch (data.type)
    {
        case TYPE_INT:

            printf("Integer: %d\n",
                   data.value.number);

            break;

        case TYPE_FLOAT:

            printf("Float: %.2f\n",
                   data.value.decimal);

            break;

        case TYPE_CHAR:

            printf("Character: %c\n",
                   data.value.letter);

            break;
    }
}

int main()
{
    struct Data data;

    data.type = TYPE_FLOAT;
    data.value.decimal = 45.5;

    display(data);

    return 0;
}

Output

Float: 45.50

14.55 Program Explanation

In the previous program, the enumeration Type identifies the kind of value stored in the union.

  • TYPE_INT represents an integer.
  • TYPE_FLOAT represents a floating-point value.
  • TYPE_CHAR represents a character.
  • The union stores the corresponding value.
  • The display() function uses the tag to select the correct member.

14.60 Chapter Summary

A union is a user-defined data type in C that allows different members to share the same memory location. Unlike a structure, the members of a union do not have separate storage.

A union is useful when a program needs to store one of several alternative types of data and memory efficiency is important.

  • A union is declared using the union keyword.
  • All members of a union share the same storage.
  • The size of a union is generally based on its largest member and alignment requirements.
  • The dot operator . accesses members through a union variable.
  • The arrow operator -> accesses members through a pointer to a union.
  • A union can be passed to and returned from functions.
  • A union can be used inside a structure.
  • A tagged union can use an additional tag to identify the currently meaningful member.
  • Unions are useful in memory-sensitive and low-level applications.

A tagged union combines a union with a separate tag that identifies which member should currently be interpreted.

They can provide a memory-efficient way to represent alternative forms of data.
