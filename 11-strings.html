Introduction to Strings

A string is a sequence of characters stored in a character array and terminated by a special null character '\0'.

Strings are used to store text such as names, addresses, messages, passwords and other character data.

Example

char name[] = "ALLIED";

Internally, the string contains the characters followed by the null character.

A L L I E D \0 | | | | | | | +----+----+----+----+----+-----+ String
Simple Definition: A string in C is a sequence of characters terminated by the null character '\0'.

Character Array

A character array is an array whose elements have the char data type. 

char name[10];

A character array can store individual characters or a string.

Example

char name[] = {'A', 'L', 'L', 'I', 'E', 'D', '\0'};

The same string can be written more conveniently as: 

char name[] = "ALLIED";

Null Character

The null character is written as '\0'. It marks the end of a C string. 

char word[] = "HELLO";
H E L L O \0 | | | | | | 0 1 2 3 4 5

Although the word HELLO contains five visible characters, the character array requires six positions when storing it as a C string because of the terminating '\0'.

Forgetting enough space for the null character can lead to incorrect string handling and undefined behavior.

String Declaration

A string can be declared using a character array.

Syntax

char string_name[size];

Examples

char name[20];

char city[30];

char message[100];

The size should be large enough to store all required characters plus the null character.

String Initialization

Strings can be initialized when they are declared.

Method 1: String Literal

char name[] = "ALLIED";

Method 2: Character List

char name[] =
{
    'A',
    'L',
    'L',
    'I',
    'E',
    'D',
    '\0'
};

Method 3: Fixed Size Array

char name[10] = "ALLIED";
Using a string literal such as char name[] = "ALLIED"; is usually the simplest way to initialize a string.

Displaying a String

The printf() function uses the %s format specifier to display a string. 

#include <stdio.h>

int main()
{
    char name[] = "ALLIED";

    printf("%s", name);

    return 0;
}

Output

ALLIED

Reading a String Using scanf()

The %s format specifier can be used with scanf() to read a word. 

#include <stdio.h>

int main()
{
    char name[30];

    printf("Enter your name: ");
    scanf("%29s", name);

    printf("Hello %s", name);

    return 0;
}

Example Output

Enter your name: Maniking
Hello Maniking
scanf("%s", ...) stops reading at whitespace. Therefore, it is not suitable by itself for reading a full sentence containing spaces.

Reading a Full Line Using fgets()

The fgets() function can read a line of text, including spaces, from standard input. 

#include <stdio.h>

int main()
{
    char name[50];

    printf("Enter your full name: ");

    fgets(name, sizeof(name), stdin);

    printf("Name: %s", name);

    return 0;
}

Example Output

Enter your full name: Ravi Kumar
Name: Ravi Kumar
Remember: scanf("%s", name) is commonly used for a single word, while fgets() can read spaces as part of the input line.

String Length Using strlen()

The strlen() function is used to find the number of characters in a string, excluding the terminating null character.

It is declared in the <string.h> header file.

Syntax

strlen(string);

Example

#include <stdio.h>
#include <string.h>

int main()
{
    char name[] = "ALLIED";

    printf("Length = %zu", strlen(name));

    return 0;
}

Output

Length = 6
Important: strlen() counts the visible characters but does not count the terminating '\0' character.

String Copy Using strcpy()

The strcpy() function copies the contents of one string into another character array.

It is declared in the <string.h> header file.

Syntax

strcpy(destination, source);

Example

#include <stdio.h>
#include <string.h>

int main()
{
    char source[] = "ALLIED";
    char destination[20];

    strcpy(destination, source);

    printf("Copied string: %s", destination);

    return 0;
}

Output

Copied string: ALLIED
The destination array must have enough space for the source string and its terminating null character.

String Concatenation Using strcat()

The strcat() function appends one string to the end of another string.

Syntax

strcat(destination, source);

Example

#include <stdio.h>
#include <string.h>

int main()
{
    char first[30] = "Hello ";
    char second[] = "World";

    strcat(first, second);

    printf("%s", first);

    return 0;
}

Output

Hello World
Make sure the destination array has enough unused space to contain the combined string.

String Comparison Using strcmp()

The strcmp() function compares two strings lexicographically.

Syntax

strcmp(string1, string2);
Return Value Meaning
0 Both strings are equal.
Less than 0 First string comes before the second.
Greater than 0 First string comes after the second.

Example

#include <stdio.h>
#include <string.h>

int main()
{
    char first[] = "Apple";
    char second[] = "Apple";

    if (strcmp(first, second) == 0)
    {
        printf("Strings are equal");
    }
    else
    {
        printf("Strings are different");
    }

    return 0;
}

Output

Strings are equal

String Functions in C

The <string.h> header provides several commonly used functions for string processing.

Function Purpose
strlen() Finds the length of a string.
strcpy() Copies one string to another.
strcat() Appends one string to another.
strcmp() Compares two strings.
strchr() Finds the first occurrence of a character.

Finding a Character Using strchr()

The strchr() function searches for the first occurrence of a specified character in a string.

Syntax

strchr(string, character);

Example

#include <stdio.h>
#include <string.h>

int main()
{
    char word[] = "PROGRAMMING";

    char *result = strchr(word, 'G');

    if (result != NULL)
    {
        printf("Character found");
    }
    else
    {
        printf("Character not found");
    }

    return 0;
}

Output

Character found

Program: Count Vowels and Consonants

#include <stdio.h>

int main()
{
    char word[100];
    int vowels = 0;
    int consonants = 0;

    printf("Enter a word: ");
    scanf("%99s", word);

    for (int i = 0; word[i] != '\0'; i++)
    {
        if (word[i] == 'a' ||

Program: Convert String to Uppercase

The toupper() function can be used to convert a character to uppercase. It is available through the <ctype.h> header file. 

#include <stdio.h>
#include <ctype.h>

int main()
{

    printf("Enter a word: ");
    scanf("%99s", word);

    for (int i = 0; word[i] != '\0'; i++)
    {
        word[i] = toupper((unsigned char)word[i]);

    return 0;

Program: Reverse a String

A string can be displayed in reverse order by starting from its last character and moving toward the first character.

#include <string.h>

int main()
{
    char word[100];

    printf("Enter a word: ");
    scanf("%99s", word);

    printf("Reverse = ");

    for (int i = (int)strlen(word) - 1; i >= 0; i--)

    }

    return 0;
}

Program: Check Palindrome String

A palindrome is a string that reads the same from left to right and right to left.

Examples

  • MADAM
  • LEVEL
  • RADAR
#include <stdio.h>
#include <string.h>

int main()
{
    char word[100];
    int palindrome = 1;

    printf("Enter a word: ");
    scanf("%99s", word);

    int length = (int)strlen(word);

    for (int i = 0; i < length / 2; i++)
    {
        if (word[i] != word[length - 1 - i])
        {
            palindrome = 0;
            break;
        }
    }

    if (palindrome)
    {
        printf("Palindrome");
    }
    else
    {
        printf("Not a palindrome");
    }

    return 0;
}

Palindrome

Program: Count Digits, Letters and Special Characters

The ctype.h functions can be used to classify characters. 

#include <stdio.h>
#include <ctype.h>

int main()
{
    char text[100];

    int letters = 0;
    int digits = 0;
    int special = 0;

    printf("Enter a string: ");
    scanf("%99s", text);

    for (int i = 0; text[i] != '\0'; i++)
    {
        if (isalpha((unsigned char)text[i]))
        {
            letters++;
        }
        else if (isdigit((unsigned char)text[i]))
        {
            digits++;
        }
        else
        {
            special++;
        }
    }

    printf("Letters = %d\n", letters);
    printf("Digits = %d\n", digits);
    printf("Special characters = %d", special);

    return 0;
}

Example Output

Enter a string: Hello123@
Letters = 5
Digits = 3
Special characters = 1

Program: Count Words in a Sentence

A sentence can contain multiple words separated by spaces. The following program counts words while handling repeated spaces. 

#include <stdio.h>
#include <ctype.h>

int main()
{
    char sentence[200];
    int words = 0;
    int insideWord = 0;

    printf("Enter a sentence: ");

    fgets(sentence, sizeof(sentence), stdin);

    for (int i = 0; sentence[i] != '\0'; i++)
    {
        if (!isspace((unsigned char)sentence[i]))
        {
            if (!insideWord)
            {
                words++;
                insideWord = 1;
            }
        }
        else
        {
            insideWord = 0;
        }
    }

    printf("Number of words = %d", words);

    return 0;
}

Example Output

Enter a sentence: C programming is easy
Number of words = 4

Program: Remove Spaces from a String

Removing the Newline from fgets()

When fgets() reads a line, the newline character may also be stored if there is enough space in the array. It can be removed when required. 

#include <stdio.h>
#include <string.h>

int main()
{
    char name[50];

    printf("Enter your name: ");

    fgets(name, sizeof(name), stdin);

    name[strcspn(name, "\n")] = '\0';

    printf("Name: %s", name);

    return 0;
}

Example Output

Enter your name: Ravi Kumar
Name: Ravi Kumar

String Reversal Using an Array

A string can also be reversed by storing its characters in reverse order in another character array. 

#include <stdio.h>
#include <string.h>

int main()
{
    char word[100];
    char reverse[100];

    printf("Enter a word: ");
    scanf("%99s", word);

    int length = (int)strlen(word);

    for (int i = 0; i < length; i++)
    {
        reverse[i] = word[length - 1 - i];
    }

    reverse[length] = '\0';

    printf("Original = %s\n", word);
    printf("Reverse = %s", reverse);

    return 0;
}

Example Output

Original = HELLO
Reverse = OLLEH

Common Errors in String Handling

  • Forgetting the null character when manually creating a C string.
  • Declaring an array that is too small for the string.
  • Accessing characters beyond the valid array bounds.
  • Using == instead of strcmp() to compare string contents.
  • Using scanf("%s", ...) when the input contains spaces.
  • Forgetting to include <string.h> when using string functions.
  • Forgetting to include <ctype.h> when using character classification or conversion functions.
  • Copying or concatenating into a destination array that is too small.

Best Practices for Strings

  • Allocate enough space for the string and its null character.
  • Prefer bounded input operations such as fgets() for complete lines.
  • Use strcmp() for comparing string contents.
  • Use strlen() when the string length is required.
  • Check destination size before copying or concatenating.
  • Use meaningful variable names.
  • Avoid accessing characters outside the valid range.
  • Include the correct standard library header files.
Best Practice: Always think about the size of the destination character array before copying or joining strings.

Summary

Strings are an important part of C programming because they allow programs to store and process text.

  • A C string is stored in a character array.
  • A string normally ends with the null character '\0'.
  • The %s format specifier is used for strings.
  • strlen() finds the length of a string.
  • strcpy() copies a string.
  • strcat() joins strings.
  • strcmp() compares strings.
  • strchr() searches for a character.
  • strstr() searches for a substring.
  • fgets() can read a complete line of text.
  • Strings are widely used in real-world applications.
Key Point: Always remember that a C string is a character sequence terminated by the null character '\0'.
