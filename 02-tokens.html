2.1 Introduction to C Tokens

Every programming language has rules for writing programs. In C programming, a program is made up of many small building blocks called tokens.

A token is the smallest meaningful unit of a C program that can be recognized by the compiler.

A simple C program may contain keywords, variable names, constants, operators, strings, and special symbols. Each of these elements has a specific meaning and forms part of the program's syntax.

Important: Tokens are the basic building blocks of a C program.

2.2 What are C Tokens?

A C token is the smallest meaningful element of a C source program that the compiler can identify.

Consider this statement: 

int age = 20;

The statement can be divided into these tokens:

Token Type
int Keyword
age Identifier
= Operator
20 Integer Constant
; Special Symbol

2.3 Types of C Tokens

C tokens can be classified into several major categories.

Type Description Example
Keywords Reserved words of C int, return, if
Identifiers User-defined names age, total
Constants Fixed values 100, 3.14
String Literals Text enclosed in double quotes "Hello"
Operators Perform operations +, -, *, =
Special Symbols Symbols used in program syntax ;, (), {}, []
C TOKENS | +-------------------+ | | Keywords Identifiers | Constants | String Literals | Operators | Special Symbols

2.4 Keywords

Keywords are reserved words that have predefined meanings in the C language.

A keyword cannot normally be used as the name of a variable, function, or other user-defined identifier.

Examples

int
float
char
if
else
for
while
return
switch
break
continue

Example:

int marks = 90;

Here, int is a keyword and marks is an identifier.

2.5 Identifiers

Identifiers are names created by programmers to identify variables, functions, arrays, structures, and other program elements.

Valid Identifiers

age
studentName
total_marks
number1
_count

Invalid Identifiers

1age
student-name
student name
return

Rules

  • An identifier can contain letters.
  • It can contain digits after the first character.
  • Underscore is allowed.
  • It cannot begin with a digit.
  • Spaces are not allowed.
  • Keywords should not be used as identifiers.
  • C identifiers are case-sensitive.

2.7 String Literals

A string literal is a sequence of characters enclosed in double quotation marks. 

printf("Welcome to ALLIED");

The text "Welcome to ALLIED" is a string literal.

Examples

"Hello"
"Programming"
"ALLIED Academy"
"Welcome Student"

2.8 Operators

Operators are symbols used to perform operations on values and variables.

Operator Type Examples
Arithmetic + - * / %
Relational == != > < >= <=
Logical && || !
Assignment = += -= *= /=
Increment / Decrement ++ --

Example

int a = 10;

Here, = and + are operators.

2.10 Tokenization Process

Before a C program is compiled into machine code, the source code is processed and analyzed. One important part of this process is recognizing meaningful lexical elements.

C SOURCE CODE | v Lexical Analysis | v Identify Tokens | +--------+---------+---------+ | | | | Keywords Names Constants Operators | v Further Compilation | v Machine Code

This process allows the compiler to understand the structure of the source program.

2.12 Program Examples

Example 1: Addition

#include <stdio.h>

int main()
{
    int a = 10;
    int b = 20;

    int sum = a + b;

    printf("Sum = %d", sum);

    return 0;
}

Output

Sum = 30

Explanation

The program contains keywords, identifiers, constants, operators, string literals, and special symbols. The compiler recognizes each of these elements as part of the program.

Example 2: Student Information

#include <stdio.h>

int main()
{
    int age = 18;
    char grade = 'A';

    printf("Age = %d\n", age);
    printf("Grade = %c", grade);

    return 0;
}

Output

Age = 18
Grade = A

2.13 Common Errors

Error 1: Invalid Identifier

int 1age;

An identifier cannot begin with a number.

Correct example: 

int age1;

Error 2: Keyword Used as Identifier

int return;

return is a reserved keyword.

Error 3: Missing Semicolon

int age = 20

Most C statements need a semicolon. 

int age = 20;

Error 4: Incorrect Character Constant

char grade = "A";

A single character should normally use single quotation marks. 

char grade = 'A';

2.14 Best Practices

  • Use meaningful identifier names.
  • Follow consistent naming conventions.
  • Keep your code properly indented.
  • Use comments when they improve understanding.
  • Check semicolons carefully.
  • Do not use keywords as identifiers.
  • Compile programs frequently while learning.
  • Read compiler error messages carefully.

2.15 Real-World Example

Consider a simple banking program: 

balance = deposit - withdrawal;

Here:

  • balance is an identifier.
  • = is an assignment operator.
