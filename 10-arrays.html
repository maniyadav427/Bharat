Chapter 10: Arrays in C

Learn how arrays store multiple values of the same data type under a single name and how arrays are used for efficient data processing in C programming.

Introduction to Arrays

An array is a collection of elements of the same data type stored under a single name.

Arrays are useful when a program needs to store and process multiple values of the same type.

For example, instead of declaring five separate variables for five student marks, an array can store all five marks using one variable name.

Without an Array

int mark1 = 80;
int mark2 = 75;
int mark3 = 90;
int mark4 = 65;
int mark5 = 88;

With an Array

int marks[5] = {80, 75, 90, 65, 88};
Simple Definition: An array is a collection of elements of the same data type stored in contiguous memory locations and accessed using an index.

Why Are Arrays Needed?

Arrays are needed when a program must store and process many values of the same data type.

  • To store multiple values using one variable name.
  • To reduce the number of variable declarations.
  • To process large amounts of similar data.
  • To make searching easier.
  • To perform sorting operations.
  • To process student marks.
  • To store numbers, temperatures, prices and other data.
  • To work efficiently with loops.

Characteristics of Arrays

  • All elements normally have the same data type.
  • Elements are stored in contiguous memory locations.
  • Each element is identified using an index.
  • Array indexing in C starts from 0.
  • The size of a fixed array is determined when it is defined.
  • Arrays can have one or more dimensions.

Array Indexing

In C, the first element of an array has index 0. If an array contains five elements, its indexes are 0, 1, 2, 3 and 4. 

int marks[5] = {80, 75, 90, 65, 88};
Index: 0 1 2 3 4 | | | | | Value: 80 75 90 65 88
Index Value
0 80
1 75
2 90
3 65
4 88
Remember: C array indexing starts from 0, not 1.

Declaration of an Array

An array is declared by specifying its data type, name and size.

Syntax

data_type array_name[size];

Examples

int numbers[10];

float prices[5];

char letters[26];

double values[20];
Declaration Meaning
int numbers[10]; Integer array with 10 elements.
float prices[5]; Float array with 5 elements.
char letters[26]; Character array with 26 elements.

Array Initialization

Array elements can be initialized when the array is declared.

Example

int numbers[5] = {10, 20, 30, 40, 50};

Individual elements can also be initialized using indexes. 

int numbers[5];

numbers[0] = 10;
numbers[1] = 20;
numbers[2] = 30;
numbers[3] = 40;
numbers[4] = 50;
When an array is initialized with fewer values than its declared size, the remaining elements are initialized to zero for an ordinary static initialization.

Accessing Array Elements

Array elements are accessed using the array name followed by an index inside square brackets. 

int numbers[5] = {10, 20, 30, 40, 50};

printf("%d", numbers[0]);
printf("%d", numbers[3]);

Output

10
40

The expression numbers[0] accesses the first element, while numbers[3] accesses the fourth element.

Example

Traversing an Array

Traversing an array means visiting each element of the array one by one.

Loops are commonly used for array traversal. 

int numbers[5] = {10, 20, 30, 40, 50};

for (int i = 0; i < 5; i++)
{
    printf("%d ", numbers[i]);
}
Important: For an array containing n elements, valid indexes are from 0 to n - 1.

Finding Sum of Array Elements

#include <stdio.h>

int main()
{
    int numbers[5] = {10, 20, 30, 40, 50};
    int sum = 0;

    for (int i = 0; i < 5; i++)
    {
        sum = sum + numbers[i];

Searching an Element in an Array

Searching means checking whether a particular value exists in an array.

Linear search checks the elements one by one from the beginning of the array. 

#include <stdio.h>

int main()
{
    int numbers[5] = {10, 20, 30, 40, 50};
    int key;
    int found = 0;

    printf("Enter element to search: ");
    scanf("%d", &key);

    for (int i = 0; i < 5; i++)
    {
        if (numbers[i] == key)
        {
            printf("Element found at index %d", i);
            found = 1;
            break;
        }
    }

    if (!found)
    {
        printf("Element not found");
    }

    return 0;
}

Example Output

Enter element to search: 30
Element found at index 2

Linear Search

Array: +----+----+----+----+----+ | 10 | 20 | 30 | 40 | 50 | +----+----+----+----+----+ | v Compare with key | v Continue until found or end of array

Linear search is simple and works even when the array is not sorted.

Counting Even and Odd Elements

#include <stdio.h>

int main()
{
    int numbers[6] = {10, 15, 22, 31, 40, 55};
    int even = 0;
    int odd = 0;

    for (int i = 0; i < 6; i++)

        if (numbers[i] % 2 == 0)

            even++;

        else
        {
            odd++;
        }

    printf("Odd elements = %d", odd);

    return 0;
}

Even elements = 3

Reversing an Array

Reversing an array means displaying its elements from the last element to the first element. 

#include <stdio.h>

int main()
{
    int numbers[5] = {10, 20, 30, 40, 50};

    printf("Reverse order:\n");

    for (int i = 4; i >= 0; i--)

        printf("%d ", numbers[i]);
    }

    return 0;

Sorting an Array

Sorting means arranging array elements in a particular order. The order may be ascending or descending.

Bubble sort is a simple sorting technique that repeatedly compares adjacent elements and swaps them when they are in the wrong order.

Bubble Sort in Ascending Order

#include <stdio.h>

int main()
{
    int numbers[5] = {50, 20, 40, 10, 30};
    int temp;

    for (int i = 0; i < 5 - 1; i++)
    {
        for (int j = 0; j < 5 - 1 - i; j++)
        {
            if (numbers[j] > numbers[j + 1])
            {
                temp = numbers[j];
                numbers[j] = numbers[j + 1];
                numbers[j + 1] = temp;
            }
        }
    }

    printf("Sorted array:\n");

    for (int i = 0; i < 5; i++)
    {
        printf("%d ", numbers[i]);
    }

    return 0;
}

Output

Sorted array:
10 20 30 40 50

Sorting in Descending Order

#include <stdio.h>

int main()
{
    int numbers[5] = {10, 50, 20, 40, 30};
    int temp;

    for (int i = 0; i < 5 - 1; i++)
    {
        for (int j = 0; j < 5 - 1 - i; j++)
        {
            if (numbers[j] < numbers[j + 1])
            {
                temp = numbers[j];
                numbers[j] = numbers[j + 1];
                numbers[j + 1] = temp;
            }
        }
    }

    printf("Descending order:\n");

    for (int i = 0; i < 5; i++)
    {
        printf("%d ", numbers[i]);
    }

    return 0;
}

Output

Descending order:
50 40 30 20 10

Two-Dimensional Array

A two-dimensional array stores data in rows and columns. It can be visualized like a table or matrix.

Syntax

data_type array_name[rows][columns];

Example

int matrix[2][3] =
{
    {10, 20, 30},
    {40, 50, 60}
};
Column 0 1 2 +-----+-----+-----+ 0 | 10 | 20 | 30 | +-----+-----+-----+ 1 | 40 | 50 | 60 | +-----+-----+-----+ Row

Accessing Two-Dimensional Array Elements

A two-dimensional array uses two indexes. The first index represents the row and the second index represents the column. 

int matrix[2][3] =
{
    {10, 20, 30},
    {40, 50, 60}
};

printf("%d", matrix[0][1]);

Output

20

Here, matrix[0][1] refers to the element in row 0 and column 1.

Reading a Two-Dimensional Array

Matrix Addition

Two matrices of the same dimensions can be added by adding their corresponding elements. 

#include <stdio.h>

int main()
{
    int a[2][2] =
    {
        {1, 2},
        {3, 4}
    };

    int b[2][2] =
    {
        {5, 6},
        {7, 8}
    };

    int sum[2][2];

    for (int i = 0; i < 2; i++)
    {
        for (int j = 0; j < 2; j++)
        {
            sum[i][j] = a[i][j] + b[i][j];
        }
    }

    printf("Sum of matrices:\n");

    for (int i = 0; i < 2; i++)
    {
        for (int j = 0; j < 2; j++)
        {
            printf("%d ", sum[i][j]);
        }

        printf("\n");
    }

    return 0;
}

Output

Sum of matrices:
6 8
10 12

Matrix Transpose

The transpose of a matrix is obtained by converting its rows into columns and its columns into rows. 

#include <stdio.h>

int main()
{
    int matrix[2][3] =
    {
        {1, 2, 3},
        {4, 5, 6}
    };

    printf("Transpose:\n");

    for (int j = 0; j < 3; j++)
    {
        for (int i = 0; i < 2; i++)
        {
            printf("%d ", matrix[i][j]);
        }

        printf("\n");
    }

    return 0;
}

Output

Transpose:
1 4
2 5
3 6

Multi-Dimensional Arrays

C supports arrays with more than two dimensions. Such arrays are called multi-dimensional arrays.

Example

int values[2][3][4];

This declaration represents a three-dimensional array. Multi-dimensional arrays are useful for representing complex structured data.

Character Arrays

A character array is an array whose elements have the char data type. Character arrays are commonly used to store strings. 

char name[6] = {'A', 'L', 'L', 'I', 'E', 'D'};

C strings are normally stored in character arrays and terminated by the null character '\0'. 

char name[] = "ALLIED";
A string such as "ALLIED" requires space for the characters plus the terminating null character.

Array and Pointer Relationship

In many expressions, the name of an array is converted to a pointer to its first element. This is an important concept when working with arrays and functions. 

int numbers[3] = {10, 20, 30};

printf("%d", *numbers);

Output

10

Here, numbers refers to the first element in this expression, so dereferencing it gives the value 10.

Array names and pointers are closely related in many C expressions, but an array itself is not a modifiable pointer.

Passing an Array to a Function

Arrays can be passed to functions. A function can receive an array and process its elements.

Example

#include <stdio.h>

{
    for (int i = 0; i < size; i++)

        printf("%d ", numbers[i]);
    }

int main()
{
    int numbers[5] = {10, 20, 30, 40, 50};

    display(numbers, 5);

    return 0;
}

Output

10 20 30 40 50

Array Size and Number of Elements

The sizeof operator can be used to determine the total size in bytes of an array.

For an array whose elements have a known type, the number of elements can commonly be calculated using: 

sizeof(array) / sizeof(array[0])

Example

#include <stdio.h>

int main()
{
    int numbers[] = {10, 20, 30, 40, 50};

    int size = sizeof(numbers) / sizeof(numbers[0]);

    printf("Number of elements = %d", size);

    return 0;
}

Output

Number of elements = 5
This calculation gives the number of elements only when numbers is actually an array in that scope. It does not generally work the same way after an array is passed to a function parameter.

Common Errors in Arrays

  • Using an index outside the valid range.
  • Forgetting that array indexes start at 0.
  • Using the wrong array size.
  • Reading more elements than the array can hold.
  • Using incorrect row or column indexes in 2D arrays.
  • Forgetting to initialize variables used for calculations.
  • Confusing the number of elements with the last index.
  • Using an incorrect loop condition.

Incorrect Example

int numbers[5];

for (int i = 0; i <= 5; i++)
{
    numbers[i] = i;
}

The valid indexes are 0 through 4. When i becomes 5, the program accesses an element outside the array.

Correct Example

int numbers[5];

for (int i = 0; i < 5; i++)
{
    numbers[i] = i;
}

Best Practices for Arrays

  • Always use valid array indexes.
  • Remember that indexing starts from 0.
  • Use loops to process array elements efficiently.
  • Keep track of the number of valid elements.
  • Avoid accessing elements beyond the array bounds.
  • Use meaningful array names.
  • Check input sizes before storing user data.
  • Use functions to organize complex array operations.
  • Test arrays with empty, small and boundary cases where appropriate.
Important: Always make sure that your loop condition matches the actual number of elements in the array.

Summary

Arrays are an important data structure in C programming. They allow multiple values of the same data type to be stored using a single variable name.

  • An array contains multiple elements of the same type.
  • Array indexing starts from 0.
  • A one-dimensional array stores elements in a single sequence.
  • A two-dimensional array stores elements using rows and columns.
  • Loops are commonly used to traverse arrays.
  • Arrays can be searched and sorted.
  • Arrays can be passed to functions.
  • Character arrays are commonly used to store strings.
  • Accessing an array outside its valid bounds results in undefined behavior.
  • Arrays are widely used in real-world applications.
Key Point: Always remember that for an array of size n, the valid indexes are 0 through n - 1.
