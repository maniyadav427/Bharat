5.1 Introduction to Operators

An operator is a symbol or keyword that tells the C language to perform an operation on one or more operands.

For example: 

int sum = a + b;

Here, + is an arithmetic operator and a and b are operands.

Simple definition: An operator performs an operation on one or more values.

5.2 Historical Background

Operators are fundamental to programming languages because programs need a way to calculate values, compare data, assign results and manipulate individual bits.

C provides a particularly rich set of operators. Its operators include arithmetic operations as well as low-level operations such as bitwise manipulation and address-related operators.

This combination is one reason C can be used for both general application programming and systems programming.

5.4 Arithmetic Operators

Arithmetic operators are used to perform mathematical operations.

Operator Name Example
+ Addition a + b
- Subtraction a - b
* Multiplication a * b
/ Division a / b
% Remainder a % b

Example

int a = 20;
int b = 6;

printf("%d\n", a + b);
printf("%d\n", a - b);
printf("%d\n", a * b);
printf("%d\n", a / b);
printf("%d\n", a % b);

Output

26
14
120
3
2
When both operands of / are integers, C performs integer division. The fractional part is discarded.

5.5 Relational Operators

Relational operators compare two values.

Operator Meaning Example
< Less than a < b
> Greater than a > b
<= Less than or equal to a <= b
>= Greater than or equal to a >= b
== Equal to a == b
!= Not equal to a != b

In C, a comparison expression produces an integer result: zero represents false and nonzero represents true.

5.6 Logical Operators

Logical operators combine or reverse conditions.

Operator Name Meaning
&& Logical AND True when both operands are true
|| Logical OR True when at least one operand is true
! Logical NOT Reverses the truth value

Example

int age = 20;

if (age >= 18 && age <= 60)
{
    printf("Eligible");
}

The condition is true only when both comparisons are true.

5.7 Assignment Operators

Assignment operators store values in variables.

Operator Meaning Equivalent Form
= Assignment a = b
+= Add and assign a = a + b
-= Subtract and assign a = a - b
*= Multiply and assign a = a * b
/= Divide and assign a = a / b
%= Remainder and assign a = a % b

Example

int number = 10;

number += 5;

printf("%d", number);

Output:

15

5.8 Increment and Decrement Operators

The increment operator ++ increases a value by one. The decrement operator -- decreases a value by one. 

int x = 10;

x++;

printf("%d\n", x);

x--;

printf("%d", x);

Output

11
10

5.9 Prefix and Postfix

The increment and decrement operators can be used before or after an expression.

Prefix

++x;
--x;

The value is changed before its value is used in the larger expression.

Postfix

x++;
x--;

The previous value is used in the larger expression before the increment or decrement takes effect.

Example

#include <stdio.h>

int main()
{
    int x = 5;

    printf("%d\n", x++);
    printf("%d\n", x);

    x = 5;

    printf("%d\n", ++x);
    printf("%d\n", x);

    return 0;
}

Output

5
6
6
6

5.10 Bitwise Operators

Bitwise operators operate on the individual bits of integer operands.

Operator Name
& Bitwise AND
| Bitwise OR
^ Bitwise XOR
~ Bitwise NOT
<< Left shift
>> Right shift

Example

int a = 5;
int b = 3;

printf("AND = %d\n", a & b);
printf("OR  = %d\n", a | b);
printf("XOR = %d\n", a ^ b);

Output

AND = 1
OR  = 7
XOR = 6

5.11 Bitwise Diagram

Consider the values 5 and 3:

5 = 0101 3 = 0011 AND (&) 0101 0011 ---- 0001 = 1 OR (|) 0101 0011 ---- 0111 = 7 XOR (^) 0101 0011 ---- 0110 = 6

5.12 Shift Operators

Shift operators move the bits of an integer value.

Left Shift

int x = 5;

printf("%d", x << 1);

Output: 

10

Right Shift

int x = 8;

printf("%d", x >> 1);

On common implementations this produces: 

4
The exact behavior of some shift operations, especially involving negative signed values, requires care. Bitwise programming is safest when you understand the type and implementation involved.

5.13 Conditional Operator

The conditional operator ? : is a compact three-operand operator.

Syntax:

condition ? expression1 : expression2;

Example

int a = 10;
int b = 20;

int max = (a > b) ? a : b;

printf("Maximum = %d", max);

Output

Maximum = 20

5.14 sizeof Operator

The sizeof operator determines the size in bytes of a type or expression. 

#include <stdio.h>

int main()
{
    int x;

    printf("Size = %zu bytes", sizeof(x));

    return 0;
}

The actual size depends on the implementation.

5.15 Address-of Operator

The unary & operator can be used to obtain the address of an object. 

int age = 20;

printf("%p", (void *)&age);
