16.1 Introduction to File Handling

A file is a collection of data stored on a storage device. Files allow information to remain available even after a program has finished execution.

Normally, variables store data temporarily in memory. When the program terminates, the data stored in ordinary variables is lost.

File handling provides a way to store data permanently in files such as text files and binary files.

Simple Definition: File handling is the process of creating, opening, reading, writing, updating and closing files using a program.

16.2 Why Is File Handling Needed?

File handling is required when information needs to be stored permanently.

  • To store data permanently.
  • To save program results.
  • To read previously stored information.
  • To maintain student records.
  • To maintain employee records.
  • To store application settings.
  • To store logs.
  • To process large amounts of data.
  • To exchange data between programs.

16.7 FILE Pointer

C uses the FILE type to represent an open file stream.

A pointer to a FILE object is commonly used when performing file operations. 

FILE *fp;

Here, fp is a file pointer.

The FILE type is declared by the standard I/O header file. 
#include <stdio.h>

  2. Open the file.

16.9 Opening a File

The fopen() function is used to open a file.

Syntax

FILE *fopen(const char *filename,
            const char *mode);

Example

FILE *fp;

fp = fopen("data.txt", "r");

The first argument specifies the file name and the second argument specifies the opening mode.

16.10 Closing a File

The fclose() function closes an opened file.

Syntax

fclose(fp);

Closing files is important because it releases resources associated with the open stream and ensures buffered output is properly handled.

Always close a file after finishing the required file operations.

16.11 Simple File Opening Program

#include <stdio.h>

int main()
{
    FILE *fp;

    fp = fopen("data.txt", "r");

    if (fp == NULL)
    {
        printf("Unable to open file.");
        return 1;
    }

    printf("File opened successfully.");

    fclose(fp);

    return 0;
}

Explanation

  • FILE *fp declares a file pointer.
  • fopen() attempts to open the file.
  • NULL indicates that opening failed.
  • fclose() closes the file.

16.13 File Opening Modes

The mode passed to fopen() determines how the file will be accessed.

Mode Purpose
r Open an existing file for reading
w Open for writing; creates or truncates the file
a Open for appending; creates if necessary
r+ Open an existing file for reading and writing
w+ Open for reading and writing; creates or truncates
a+ Open for reading and appending

16.14 Binary File Modes

The character b can be added to a mode when binary mode is required.

Mode Meaning
rb Read binary file
wb Write binary file
ab Append binary file
rb+ Read and write binary file
wb+ Read and write, creating or truncating binary file
ab+ Read and append binary file

16.15 Mode r

The r mode opens an existing file for reading. If the file does not exist, opening fails. 

FILE *fp;

fp = fopen("data.txt", "r");
The r mode does not create a missing file.

16.16 Mode w

The w mode opens a file for writing. If the file does not exist, it is created. If it already exists, its previous contents are discarded. 

FILE *fp;

fp = fopen("data.txt", "w");
Be careful with w mode because opening an existing file for writing truncates its contents.

16.17 Mode a

The a mode opens a file for appending. New data is written at the end of the file. 

FILE *fp;

fp = fopen("data.txt", "a");

If the file does not exist, it is created.

16.18 Mode r+

The r+ mode opens an existing file for both reading and writing. 

FILE *fp;

fp = fopen("data.txt", "r+");

The file must already exist.

16.19 Mode w+

The w+ mode opens a file for both reading and writing.

If the file exists, its contents are truncated. If it does not exist, a new file is created. 

FILE *fp;

fp = fopen("data.txt", "w+");

16.20 Mode a+

The a+ mode opens a file for reading and appending. 

FILE *fp;

fp = fopen("data.txt", "a+");

New output is appended to the end of the file.

16.21 Writing a Character Using fputc()

The fputc() function writes one character to a file stream.

Syntax

fputc(character, file_pointer);

Example

#include <stdio.h>

int main()
{
    FILE *fp;

    fp = fopen("data.txt", "w");

    if (fp == NULL)
    {
        printf("File could not be opened.");
        return 1;
    }

    fputc('A', fp);

    fclose(fp);

    printf("Character written.");

    return 0;
}

Output

Character written.

The file data.txt will contain: 

A

16.22 Reading a Character Using fgetc()

The fgetc() function reads one character from a file stream.

Example

#include <stdio.h>

int main()
{
    FILE *fp;
    int ch;

    fp = fopen("data.txt", "r");

    if (fp == NULL)
    {
        printf("File could not be opened.");
        return 1;
    }

    ch = fgetc(fp);

    if (ch != EOF)
    {
        printf("Character = %c", ch);
    }

    fclose(fp);

    return 0;
}

Output

Character = A
The return value of fgetc() should be stored in an int so it can also represent the special EOF value.

Syntax

16.30 Formatted File Input Using fscanf()

The fscanf() function reads formatted data from a file.

Syntax

fscanf(file_pointer, "format", &variables);

Example

#include <stdio.h>

int main()
{
    FILE *fp;

    char name[30];
    int age;

    fp = fopen("student.txt", "r");

    if (fp == NULL)
    {
        printf("File could not be opened.");
        return 1;
    }

    fscanf(fp, "Name: %29s", name);
    fscanf(fp, "Age: %d", &age);

    printf("Name = %s\n", name);
    printf("Age = %d\n", age);

    fclose(fp);

    return 0;
}

Example Output

Name = Ravi
Age = 18
When using fscanf() with strings, remember that %s stops at whitespace. For complete lines, fgets() is often more appropriate.

16.33 Binary File Handling

Binary file handling allows a program to read and write objects as sequences of bytes.

The two important functions for binary data are:

  • fread()
  • fwrite()

16.34 fwrite() Function

The fwrite() function writes blocks of data to a binary file.

Syntax

fwrite(pointer, size, count, file_pointer);

Example

#include <stdio.h>

struct Student
{
    int id;
    char name[30];
};

int main()
{
    FILE *fp;

    struct Student student =
    {
        101,
        "Ravi"
    };

    fp = fopen("student.dat", "wb");

    if (fp == NULL)
    {
        printf("File could not be opened.");
        return 1;
    }

    fwrite(&student,
           sizeof(student),
           1,
           fp);

    fclose(fp);

    printf("Data written successfully.");

    return 0;
}

Output

Data written successfully.

16.35 fread() Function

The fread() function reads blocks of data from a binary file.

Syntax

fread(pointer, size, count, file_pointer);

Example

#include <stdio.h>

struct Student
{
    int id;
    char name[30];
};

int main()
{
    FILE *fp;

    struct Student student;

    fp = fopen("student.dat", "rb");

    if (fp == NULL)
    {
        printf("File could not be opened.");
        return 1;
    }

    if (fread(&student,
              sizeof(student),
              1,
              fp) == 1)
    {
        printf("ID = %d\n",
               student.id);

        printf("Name = %s\n",
               student.name);
    }

    fclose(fp);

    return 0;
}

Output

ID = 101
Name = Ravi

16.39 File Position Indicator

An open file stream maintains a current file position. Reading and writing operations normally occur relative to this position.

FILE | |---- Data | |---- Data | |---- Data | v Current Position

File positioning functions allow a program to move this position.

16.40 fseek() Function

The fseek() function changes the current position of a file stream.

Syntax

fseek(file_pointer,
      offset,
      origin);

Common origins include:

  • SEEK_SET – beginning of file
  • SEEK_CUR – current position
  • SEEK_END – end of file

Example

fseek(fp, 0, SEEK_SET);

This moves the file position to the beginning.

16.41 ftell() Function

The ftell() function returns the current file position as a value of type long.

Syntax

long position;

position = ftell(fp);

Example

#include <stdio.h>

int main()
{
    FILE *fp;
    long position;

    fp = fopen("data.txt", "r");

    if (fp == NULL)
    {
        return 1;
    }

    position = ftell(fp);

    printf("Position = %ld",
           position);

    fclose(fp);

    return 0;
}

Output

Position = 0

16.42 rewind() Function

The rewind() function moves the file position back to the beginning of the file.

Syntax

rewind(fp);

Example

rewind(fp);

It is useful when a program needs to read the file again from the beginning.

16.43 File Position Functions Comparison

Function Purpose
fseek() Moves the file position
ftell() Reports the current file position
rewind() Moves position to the beginning

16.44 Random Access to a File

Random access means moving directly to a particular position in a file instead of reading everything from the beginning. 

fseek(fp, 10, SEEK_SET);

This requests a position relative to the beginning of the stream.

Random access is useful when working with structured data where a program needs to reach a particular part of a file.

16.45 File End Indicator and EOF

EOF is a special value used by input functions to indicate that no more input can be read from the stream. 

int ch;

while ((ch = fgetc(fp)) != EOF)
{
    putchar(ch);
}

The variable is declared as int because it must be able to represent every possible character value as well as the special EOF value.

16.46 feof() Function

The feof() function tests whether the end-of-file indicator for a stream is set.

Syntax

feof(fp);

A common pattern is to test the result of the read operation itself rather than using feof() as the loop condition. 

while (fgets(text, sizeof(text), fp) != NULL)
{
    printf("%s", text);
}

16.47 File Error Checking

File operations can fail. A program should check whether opening and reading or writing operations succeed. 

FILE *fp;

fp = fopen("data.txt", "r");

if (fp == NULL)
{
    printf("File opening failed.");
    return 1;
}
Never assume that a file always exists or that every file operation will succeed.

16.48 perror() Function

The perror() function can display a system-provided error message associated with the most recent library operation that set the error indicator. 

#include <stdio.h>

int main()
{
    FILE *fp;

    fp = fopen("missing.txt", "r");

    if (fp == NULL)
    {
        perror("File error");
        return 1;
    }

    fclose(fp);

    return 0;
}

The exact message depends on the operating system and environment.

16.59 Common File Handling Errors

Error 1: Not checking fopen()

fp = fopen("data.txt", "r");

fgets(text, 100, fp);

If opening fails, using a null file pointer can cause undefined behavior.

Always check: 

if (fp == NULL)
{
    printf("File error");
    return 1;
}

Error 2: Forgetting fclose()

Leaving files open unnecessarily can waste system resources and may prevent buffered output from being properly handled.

Error 3: Using w accidentally

Opening an existing file with w truncates its contents.

Error 4: Wrong file mode

Use a mode that matches the intended operation, such as r, w, a, rb or wb.

16.60 Best Practices for File Handling

  • Always include <stdio.h> when using standard C file I/O functions.
  • Always check whether fopen() returned NULL.
  • Use the correct file mode.
  • Close files with fclose().
  • Check the return value of important read and write operations.
  • Use fgets() when reading lines of text.
  • Use fread() and fwrite() for binary data when appropriate.
  • Be careful when using w mode because it truncates an existing file.
  • Use meaningful file names.
  • Handle errors clearly.

16.64 Advantages of File Handling

  • Permanent Storage: Data can be stored even after the program terminates.
  • Large Data Storage: Files can store large amounts of information.
  • Data Reusability: Stored data can be used again later.
  • Easy Data Management: Information can be organized into files.
  • Data Sharing: Files can be used to exchange information between programs.
  • Reduced Re-entry: Previously stored information does not need to be entered again.
  • Useful for Records: Files are useful for student, employee, customer and inventory records.

16.65 Disadvantages of File Handling

  • File operations can be slower than accessing data already in memory.
  • Files can become corrupted because of software, hardware or storage problems.
  • Incorrect file modes can accidentally modify or delete existing contents.
  • Programs must handle file errors properly.
  • Text files may require additional processing when handling structured data.
  • Binary files may not be directly readable by humans.

16.69 Common Errors in File Handling

❌ Error 1: Forgetting stdio.h

#include <stdio.h>

Standard C file I/O functions are declared through stdio.h.

❌ Error 2: Not Checking NULL

fp = fopen("data.txt", "r");

if (fp == NULL)
{
    printf("File opening failed.");
    return 1;
}

❌ Error 3: Forgetting fclose()

Always close files after completing the required operations.

❌ Error 4: Using Wrong Mode

Select the mode according to the required operation. For example, use r for reading and a for appending.

❌ Error 5: Accidentally Using w Mode

Opening an existing file using w truncates its contents.

16.70 Best Practices

  1. Always check the result of fopen().
  2. Use the correct file mode.
  3. Close every successfully opened file.
  4. Check important read and write return values.
  5. Use meaningful file names.
  6. Avoid accidentally overwriting important files.
  7. Use text files when human readability is important.
  8. Use binary files when binary representation is appropriate.
  9. Keep file operations organized and easy to understand.
  10. Handle possible errors clearly.

16.72 Summary

File handling is an important feature of C programming that allows programs to store and retrieve information from external files.

C provides many standard functions for file operations. Files can be opened using fopen(), processed using functions such as fgetc(), fputc(), fgets(), fputs(), fprintf(), fscanf(), fread() and fwrite(), and finally closed using fclose().

File positioning functions such as fseek(), ftell() and rewind() provide additional control over the current file position.
