Chapter 12: Pointers in C

Learn how pointers store memory addresses and how they are used for accessing data, working with arrays, passing values to functions and performing dynamic memory operations.

After completing this chapter, you will be able to:

  • Understand memory addresses.
  • Declare and initialize pointers.
  • Use the address-of operator.
  • Use the dereference operator.
  • Understand pointer arithmetic.
  • Understand the relationship between arrays and pointers.
  • Pass addresses to functions.
  • Understand pointer-to-pointer concepts.
  • Understand common pointer errors.

Introduction to Pointers

A pointer is a variable that stores the memory address of another variable.

Normal variables store values, while pointer variables store addresses.

Simple Example

int number = 10;

int *ptr = &number;

Here, number stores the value 10 and ptr stores the address of number.

Simple Definition: A pointer is a variable that stores the memory address of another variable.

Why Are Pointers Needed?

Pointers are one of the most important features of C. They provide direct access to memory addresses and allow programs to work efficiently with data.

  • Accessing variables through their addresses.
  • Passing variables to functions by address.
  • Modifying variables inside functions.
  • Processing arrays efficiently.
  • Working with strings.
  • Dynamic memory allocation.
  • Creating linked lists and other data structures.
  • Working with structures.

Memory Address

Every variable stored in computer memory has an address. The address identifies the location where the variable's data is stored. 

int number = 10;
Variable +---------+ | number | | 10 | +---------+ | | v Memory Address

The address of a variable can be obtained using the address-of operator &. 

printf("%p", (void *)&number);

Address-of Operator (&)

The address-of operator & returns the memory address of a variable.

Example

#include <stdio.h>

int main()
{
    int number = 25;

    printf("Value = %d\n", number);
    printf("Address = %p", (void *)&number);

    return 0;
}

Example Output

Value = 25
Address = 0x7ffd...
The actual memory address can be different every time the program runs.

Pointer Declaration

A pointer is declared using the * symbol.

Syntax

data_type *pointer_name;

Examples

int *ptr;

float *price;

char *letter;

double *value;

The pointer type should correspond to the type of object whose address it is intended to point to.

Pointer Initialization

A pointer can be initialized with the address of a compatible variable. 

#include <stdio.h>

int main()
{
    int number = 50;

    int *ptr = &number;

    printf("Number = %d\n", number);
    printf("Pointer = %p", (void *)ptr);

    return 0;
}

Output

Number = 50
Pointer = 0x7ffd...

Dereference Operator (*)

The dereference operator * is used with a pointer to access the value stored at the address contained in that pointer. 

#include <stdio.h>

int main()
{
    int number = 100;

    int *ptr = &number;

    printf("Value = %d", *ptr);

    return 0;
}

Output

Value = 100
Remember: &number means "address of number".
*ptr means "value stored at the address in ptr".

Pointer Diagram

int number = 25; int *ptr = &number; ptr | | stores address v +-----------+ | 25 | | number | +-----------+ ^ | memory address

The pointer does not normally store the value 25 directly. It stores the address where 25 is located.

Pointer and Variable Relationship

A pointer and a normal variable are different, but they are connected through a memory address. 

int number = 25;
int *ptr = &number;
Expression Meaning
number Value stored in number
&number Address of number
ptr Address stored in ptr
*ptr Value stored at the address in ptr

Changing a Value Using a Pointer

A pointer can be used to modify the value of the variable to which it points. 

#include <stdio.h>

int main()
{
    int number = 10;

    int *ptr = &number;

    printf("Before = %d\n", number);

    *ptr = 50;

    printf("After = %d", number);

    return 0;
}

Output

Before = 10
After = 50
Changing *ptr changes the value of the variable whose address is stored in the pointer.

Pointer Data Types

Pointers can point to variables of different data types. The pointer type should normally match the type of the object it points to.

Variable Pointer
int number; int *ptr;
float price; float *ptr;
char letter; char *ptr;
double value; double *ptr;

Example

#include <stdio.h>

int main()
{
    int number = 10;
    float price = 25.5f;
    char letter = 'A';

    int *p1 = &number;
    float *p2 = &price;
    char *p3 = &letter;

    printf("%d\n", *p1);
    printf("%.2f\n", *p2);
    printf("%c", *p3);

    return 0;
}

Output

10
25.50
A

Pointer Arithmetic

Pointer arithmetic allows a pointer to move between elements of an array.

Common pointer operations include:

  • Incrementing a pointer.
  • Decrementing a pointer.
  • Adding an integer to a pointer.
  • Subtracting an integer from a pointer.
  • Subtracting two pointers that refer into the same array.

Example

#include <stdio.h>

int main()
{
    int numbers[] = {10, 20, 30};

    int *ptr = numbers;

    printf("%d\n", *ptr);

    ptr++;

    printf("%d\n", *ptr);

    ptr++;

    printf("%d", *ptr);

    return 0;
}

Output

10
20
30

Pointer Increment

When a pointer is incremented, it moves to the next element of the type it points to. 

int numbers[] = {10, 20, 30};

int *ptr = numbers;

printf("%d\n", *ptr);

ptr++;

printf("%d", *ptr);

Output

10
20
Pointer arithmetic automatically accounts for the size of the pointed-to type. For example, an int * moves by one int element when incremented.

Pointer Decrement

The decrement operator moves a pointer to the previous element of an array. 

#include <stdio.h>

int main()
{
    int numbers[] = {10, 20, 30};

    int *ptr = &numbers[2];

    printf("%d\n", *ptr);

    ptr--;

    printf("%d", *ptr);

    return 0;
}

Output

30
20

Pointer and Array Relationship

The name of an array is converted to a pointer to its first element in many expressions. 

int numbers[3] = {10, 20, 30};

The following expressions access the first element: 

numbers[0]

*numbers

Both produce the value 10.

Example

#include <stdio.h>

int main()
{
    int numbers[] = {10, 20, 30};

    printf("%d\n", numbers[0]);
    printf("%d\n", *numbers);

    printf("%d\n", numbers[1]);
    printf("%d", *(numbers + 1));

    return 0;
}

Output

10
10
20
20

Accessing Array Elements Using Pointers

A pointer can be used to traverse an array. 

#include <stdio.h>

int main()
{
    int numbers[] = {10, 20, 30, 40, 50};

    int *ptr = numbers;

    for (int i = 0; i < 5; i++)
    {
        printf("%d ", *(ptr + i));
    }

    return 0;
}

Output

10 20 30 40 50

Pointer to Pointer

A pointer to pointer is a pointer variable that stores the address of another pointer.

Example

#include <stdio.h>

int main()
{
    int number = 100;

    int *ptr = &number;

    int **ptr2 = &ptr;

    printf("Number = %d\n", number);

    printf("Using ptr = %d\n", *ptr);

    printf("Using ptr2 = %d", **ptr2);

    return 0;
}

Output

Number = 100
Using ptr = 100
Using ptr2 = 100
number | v +-------+ | 100 | +-------+ ^ | ptr ^ | ptr2

Null Pointer

A null pointer is a pointer that does not point to a valid object or function.

In C, the null pointer constant is commonly represented by NULL. 

#include <stdio.h>

int main()
{
    int *ptr = NULL;

    if (ptr == NULL)
    {
        printf("Pointer is NULL");
    }

    return 0;
}

Output

Pointer is NULL
Do not dereference a null pointer. An expression such as *ptr when ptr == NULL has undefined behavior.

Pointer to a Function

A function pointer is a pointer that stores the address of a function. It can then be used to call that function.

Example

#include <stdio.h>

void message()
{
    printf("Hello from function pointer");
}

int main()
{
    void (*ptr)();

    ptr = message;

    (*ptr)();

    return 0;
}

Output

Hello from function pointer
Function pointers are useful in callbacks, menus, event handling and other advanced programming techniques.

Passing Pointer to a Function

A pointer can be passed to a function when the function needs access to the original variable. 

#include <stdio.h>

void changeValue(int *ptr)
{
    *ptr = 100;
}

int main()
{
    int number = 25;

    printf("Before = %d\n", number);

    changeValue(&number);

    printf("After = %d", number);

    return 0;
}

Output

Before = 25
After = 100

The function receives the address of number. Therefore, it can modify the original variable.

Call by Value and Call by Address

C normally passes function arguments by value. When an address is passed through a pointer, the function can modify the original object through that address.

Feature Passing a Value Passing an Address
What is passed? Copy of the value Address of the object
Original value can be modified? Not through the parameter Yes, through the pointer
Uses pointer? No Yes

Program: Swap Two Numbers Using Pointers

Pointers can be used to swap the values of two variables inside a function. 

#include <stdio.h>

void swap(int *a, int *b)
{
    int temp;

    temp = *a;
    *a = *b;
    *b = temp;
}

int main()
{
    int x = 10;
    int y = 20;

    printf("Before swap:\n");
    printf("x = %d\n", x);
    printf("y = %d\n", y);

    swap(&x, &y);

    printf("After swap:\n");
    printf("x = %d\n", x);
    printf("y = %d", y);

    return 0;
}

Output

Before swap:
x = 10
y = 20

After swap:
x = 20
y = 10

Pointer with Strings

Character pointers are commonly used to traverse and process strings. 

#include <stdio.h>

int main()
{
    char word[] = "HELLO";

    char *ptr = word;

    while (*ptr != '\0')
    {
        printf("%c ", *ptr);
        ptr++;
    }

    return 0;
}

Output

H E L L O

The pointer starts at the first character and moves forward until it reaches the null character.

Pointer with Character Arrays

#include <stdio.h>

int main()
{
    char name[] = "ALLIED";

    char *ptr = name;

    printf("String = %s\n", ptr);

    printf("First character = %c", *ptr);

    return 0;
}

Output

String = ALLIED
First character = A

Pointer to Structure

A pointer can point to a structure variable. The arrow operator -> is commonly used to access structure members through a pointer. 

#include <stdio.h>

struct Student
{
    int age;
    float marks;
};

int main()
{
    struct Student student = {18, 85.5f};

    struct Student *ptr = &student;

    printf("Age = %d\n", ptr->age);
    printf("Marks = %.2f", ptr->marks);

    return 0;
}

Output

Age = 18
Marks = 85.50

Pointer to Structure: . vs ->

When accessing a structure directly, the dot operator . is used. When accessing a structure through a pointer, the arrow operator -> is used.

Situation Operator Example
Structure variable . student.age
Pointer to structure -> ptr->age

Pointer Arithmetic with Arrays

Pointer arithmetic is particularly useful when processing arrays. 

#include <stdio.h>

int main()
{
    int numbers[] = {10, 20, 30, 40, 50};

    int *ptr = numbers;

    for (int i = 0; i < 5; i++)
    {
        printf("%d ", *(ptr + i));
    }

    return 0;
}

Output

10 20 30 40 50
ptr | v +----+----+----+----+----+ | 10 | 20 | 30 | 40 | 50 | +----+----+----+----+----+ 0 1 2 3 4 *(ptr + 0) = 10 *(ptr + 1) = 20 *(ptr + 2) = 30 *(ptr + 3) = 40 *(ptr + 4) = 50

Comparing Pointers

Pointers can be compared when they point into the same array or when comparing against a null pointer. 

#include <stdio.h>

int main()
{
    int numbers[] = {10, 20, 30};

    int *p1 = &numbers[0];
    int *p2 = &numbers[2];

    if (p1 < p2)
    {
        printf("p1 points before p2");
    }

    return 0;
}

Output

p1 points before p2
Pointer comparisons such as < and > are meaningful for pointers into the same array object. Comparing unrelated object pointers using relational operators is not generally valid for determining their memory ordering.

Subtracting Pointers

Two pointers into the same array can be subtracted to find the number of elements between them. 

#include <stdio.h>

int main()
{
    int numbers[] = {10, 20, 30, 40, 50};

    int *p1 = &numbers[1];
    int *p2 = &numbers[4];

    printf("Difference = %td", p2 - p1);

    return 0;
}

Output

Difference = 3

The result represents the number of array elements between the two pointer positions.

Pointer and sizeof

The sizeof operator applied to a pointer gives the size of the pointer itself, not the size of the object it points to. 

#include <stdio.h>

int main()
{
    int number = 10;

    int *ptr = &number;

    printf("Size of number = %zu bytes\n",
           sizeof(number));

    printf("Size of pointer = %zu bytes",
           sizeof(ptr));

    return 0;
}
The exact size of a pointer depends on the platform and implementation.

Dynamic Memory Allocation

Dynamic memory allocation allows a program to request memory while the program is running. In C, dynamic memory is managed using functions provided by <stdlib.h>.

The main dynamic memory functions are:

Function Purpose
malloc() Allocates a block of uninitialized memory.
calloc() Allocates memory for multiple elements and initializes it to zero.
realloc() Changes the size of a previously allocated memory block.
free() Releases dynamically allocated memory.

malloc() Function

The malloc() function allocates a specified number of bytes of memory.

Syntax

pointer = malloc(number_of_bytes);

Example

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int *ptr;

    ptr = malloc(sizeof(int));

    if (ptr == NULL)
    {
        printf("Memory allocation failed");
        return 1;
    }

    *ptr = 100;

    printf("Value = %d", *ptr);

    free(ptr);

    return 0;
}

Output

Value = 100
Always check whether malloc() returned NULL before using the allocated memory.

calloc() Function

The calloc() function allocates memory for a specified number of elements and initializes all allocated bytes to zero.

Syntax

pointer = calloc(number_of_elements,
                  size_of_each_element);

Example

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int *numbers;

    numbers = calloc(5, sizeof(int));

    if (numbers == NULL)
    {
        printf("Memory allocation failed");
        return 1;
    }

    for (int i = 0; i < 5; i++)
    {
        printf("%d ", numbers[i]);
    }

    free(numbers);

    return 0;
}

Output

0 0 0 0 0

malloc() vs calloc()

Feature malloc() calloc()
Arguments One size argument Number of elements and size of each element
Initialization Memory is uninitialized Allocated bytes are initialized to zero
Header <stdlib.h> <stdlib.h>
Return value Pointer to allocated memory or NULL Pointer to allocated memory or NULL

realloc() Function

The realloc() function changes the size of a previously allocated memory block.

Syntax

pointer = realloc(pointer, new_size);

Example

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int *numbers;

    numbers = malloc(3 * sizeof(int));

    if (numbers == NULL)
    {
        printf("Memory allocation failed");
        return 1;
    }

    numbers[0] = 10;
    numbers[1] = 20;
    numbers[2] = 30;

    int *temp = realloc(numbers, 5 * sizeof(int));

    if (temp == NULL)
    {
        free(numbers);
        printf("Memory reallocation failed");
        return 1;
    }

    numbers = temp;

    numbers[3] = 40;
    numbers[4] = 50;

    for (int i = 0; i < 5; i++)
    {
        printf("%d ", numbers[i]);
    }

    free(numbers);

    return 0;
}

Output

10 20 30 40 50

free() Function

Dynamically allocated memory should be released when it is no longer required.

The free() function releases memory previously allocated by malloc(), calloc(), or realloc(). 

int *ptr = malloc(sizeof(int));

/* Use allocated memory */

free(ptr);
Accessing dynamically allocated memory after it has been released can cause undefined behavior. After freeing a pointer, it is often good practice to set it to NULL if the pointer will remain in use.

Dynamic Array Using malloc()

A pointer can be used to work with an array whose size is decided at runtime. 

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int n;

    printf("Enter number of elements: ");
    scanf("%d", &n);

    if (n <= 0)
    {
        printf("Invalid size");
        return 0;
    }

    int *numbers = malloc((size_t)n * sizeof(int));

    if (numbers == NULL)
    {
        printf("Memory allocation failed");
        return 1;
    }

    for (int i = 0; i < n; i++)
    {
        numbers[i] = (i + 1) * 10;
    }

    printf("Elements:\n");

    for (int i = 0; i < n; i++)
    {
        printf("%d ", numbers[i]);
    }

    free(numbers);

    return 0;
}

Example Output

Enter number of elements: 5
Elements:
10 20 30 40 50

Dangling Pointer

A dangling pointer is a pointer that refers to memory that is no longer valid for use.

Example of a Dangerous Situation

int *ptr = malloc(sizeof(int));

if (ptr != NULL)
{
    *ptr = 50;
    free(ptr);

    /* ptr should not be dereferenced here */
}

After free(ptr), the memory is no longer available to the program through that allocation.

A common defensive practice is: 
free(ptr);
ptr = NULL;

Wild Pointer

A wild pointer is an uninitialized pointer that does not point to a valid object.

Incorrect

int *ptr;

*ptr = 100;
The pointer has not been initialized to a valid address. Dereferencing it can cause undefined behavior.

Correct Example

int number = 100;

int *ptr = &number;

printf("%d", *ptr);

Void Pointer

A void * is a generic object pointer. It can hold the address of an object of any object type, but it must be converted to an appropriate pointer type before dereferencing it in standard C. 

#include <stdio.h>

int main()
{
    int number = 25;

    void *ptr = &number;

    printf("Value = %d", *(int *)ptr);

    return 0;
}

Output

Value = 25
A void pointer does not have a specific object type, so the program must use the correct type when accessing the object through it.

Constant Pointers and Pointers to Constants

The position of the const keyword changes what can be modified.

Pointer to Constant

const int number = 10;

const int *ptr = &number;

The value cannot be modified through ptr.

Constant Pointer

int number = 10;

int *const ptr = &number;

The pointer itself cannot be changed to point somewhere else, but the pointed-to value can be modified through it.

Constant Pointer to Constant

const int number = 10;

const int *const ptr = &number;

Neither the pointer nor the pointed-to value can be modified through ptr.

Common Pointer Errors

  • Using an uninitialized pointer.
  • Dereferencing a NULL pointer.
  • Accessing memory after it has been freed.
  • Accessing memory outside an array.
  • Using an incompatible pointer type incorrectly.
  • Forgetting to free dynamically allocated memory.
  • Freeing the same allocation more than once.
  • Losing the original pointer to dynamically allocated memory.

Real-World Applications of Pointers

Pointers are widely used in systems programming and in many important C programming techniques.

  • Dynamic memory management.
  • Operating system development.
  • Embedded systems.
  • Device drivers.
  • Linked lists.
  • Trees and graphs.
  • Dynamic arrays.
  • Function callbacks.
  • String processing.
  • Structure manipulation.

Advantages of Pointers

  • Provide direct access to memory addresses.
  • Allow functions to modify caller-owned objects.
  • Support dynamic memory allocation.
  • Make array and string processing flexible.
  • Help implement dynamic data structures.
  • Support function pointers and callbacks.

Disadvantages and Risks of Pointers

  • Incorrect pointer use can cause undefined behavior.
  • Dereferencing invalid pointers can crash a program.
  • Memory leaks can occur when allocated memory is not freed.
  • Dangling pointers can access invalid memory.
  • Pointer arithmetic can be dangerous when array boundaries are ignored.
  • Pointer-based programs can be more difficult to debug.

Best Practices for Pointers

  • Always initialize pointers before using them.
  • Use NULL when a pointer intentionally points to no object.
  • Check the result of dynamic memory allocation.
  • Never dereference a NULL or invalid pointer.
  • Do not access memory after it has been freed.
  • Free dynamically allocated memory when it is no longer required.
  • Avoid accessing memory outside array boundaries.
  • Use meaningful pointer names.
  • Keep pointer operations simple and clear.
Important: A pointer is powerful because it gives access to an address, but incorrect pointer operations can result in serious programming errors.

Summary

Pointers are variables that store memory addresses. They are one of the most powerful features of the C programming language.

  • A pointer stores the address of an object.
  • The & operator obtains an address.
  • The * operator dereferences a pointer.
  • Pointers can be used with arrays and strings.
  • Pointers can be passed to functions.
  • Pointer-to-pointer variables store addresses of pointers.
  • NULL pointers represent pointers that do not point to a valid object.
  • Dynamic memory can be managed using malloc(), calloc(), realloc() and free().
  • Pointers can point to structures and functions.
  • Careful pointer management is essential for safe C programming.
