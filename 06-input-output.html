Chapter 6: Input and Output in C

Learn how C programs communicate with users using standard input and output functions such as printf(), scanf(), getchar(), putchar(), fgets() and puts().

After completing this chapter, you will be able to:

  • Use getchar() and putchar().
  • Use fgets() and puts() for text input and output.

  • Handle simple user input correctly.
  • Write complete input/output programs.

6.1 Introduction to Input and Output

Input means receiving data from an external source, usually from the user through the keyboard. Output means displaying information, commonly on the screen.

Input and output make programs interactive. Instead of using only fixed values, a program can ask the user for information, process it and display a result. 

Enter your age: 20

Your age is 20
Simple definition: Input is data supplied to a program. Output is information produced by a program.

6.2 Historical Background

C provides input and output facilities through its standard library. The standard I/O library is declared in the header file stdio.h.

Functions such as printf() and scanf() became widely associated with C programming because they provide convenient formatted console input and output.

The C standard library also provides character and line-based functions such as getchar(), putchar(), fgets() and puts().

6.3 The stdio.h Header File

The standard input/output header is included using: 

#include <stdio.h>

It provides declarations for many standard input and output functions and related facilities.

6.5 printf() Function

The printf() function is used to write formatted output to the standard output stream.

Basic syntax:

printf("format string", values);

Simple Example

#include <stdio.h>

int main()
{
    printf("Hello World!");

    return 0;
}

Output

Hello World!

6.6 Printing Variables

Format specifiers are used to tell printf() how a value should be formatted. 

#include <stdio.h>

int main()
{
    int age = 20;
    float price = 99.50f;
    char grade = 'A';

    printf("Age = %d\n", age);
    printf("Price = %.2f\n", price);
    printf("Grade = %c\n", grade);

    return 0;
}

Output

Age = 20
Price = 99.50
Grade = A

6.7 Common Format Specifiers

Specifier Common Use Example
%d Signed decimal integer printf("%d", age);
%u Unsigned decimal integer printf("%u", count);
%f Floating-point output in printf printf("%f", price);
%c Character printf("%c", grade);
%s String printf("%s", name);
%x Unsigned hexadecimal printf("%x", number);
%o Unsigned octal printf("%o", number);
%p Pointer address printf("%p", (void *)ptr);
Format specifiers depend on the function and the type being processed. Always use the appropriate specification for the particular input or output operation.
