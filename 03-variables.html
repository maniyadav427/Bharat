Chapter 3: Variables in C

Learn how variables store data, how to declare and initialize them, and how variables are used in C programs.

  • Assign and modify values.
  • Understand variable naming rules.
  • Understand local and global variables.

3.1 Introduction to Variables

A variable is a named memory location used to store a value that can change while a program is running.

For example, a program that calculates the total marks of a student needs a place to store marks. A variable can provide that storage. 

int marks = 85;

In this statement, marks is a variable that stores the integer value 85.

Simple definition: A variable is a named storage location whose value can be changed during program execution.

3.2 Historical Background

The concept of variables is fundamental to virtually every general-purpose programming language. C inherited many important ideas about variables from earlier languages while providing strong control over data types and memory.

C's approach to variables is closely connected with its emphasis on efficient compiled programs. A variable can be associated with a particular data type, allowing the compiler to understand the kind of value being stored.

This strong relationship between variables, data types and memory is one of the concepts that makes C especially useful for learning how computers represent and manipulate data.

3.3 Features of Variables

  • Named Storage: Each variable has a name used by the program.
  • Data Type: Every variable declaration specifies a type.
  • Changeable Value: A variable's value can usually be changed after declaration.
  • Memory Allocation: Variables require storage during program execution.
  • Scope: A variable is accessible only within the region where it is visible.
  • Lifetime: Variables exist according to their storage duration.

3.4 Variable Declaration

Before using a variable, it is normally declared with a data type and a name.

The general syntax is:

data_type variable_name;

Examples

int age;
float price;
char grade;
double distance;
Declaration Data Type Variable
int age; int age
float price; float price
char grade; char grade
double distance; double distance

3.5 Variable Initialization

Initialization means giving a variable an initial value when it is declared. 

int age = 18;
float price = 99.50f;
char grade = 'A';

Initialization is useful because it gives the variable a known value before it is used.

Good practice: Initialize variables when appropriate instead of relying on an unknown or unintended value.

3.6 Assignment

The assignment operator = is used to place a value into a variable. 

int score;

score = 75;

The value can later be changed: 

score = 90;

After the second assignment, the value stored in score is 90.

3.7 Declaring Multiple Variables

Multiple variables of the same type can be declared in a single declaration. 

int a, b, c;

They can also be initialized: 

int a = 10, b = 20, c = 30;
Although declaring several variables together is valid, separate declarations can sometimes make larger programs easier to read.

3.8 Rules for Naming Variables

Variable names are identifiers, so they follow the identifier rules of C.

Rules

  1. A variable name can contain letters, digits and underscores.
  2. It cannot begin with a digit.
  3. Spaces are not allowed.
  4. Special symbols such as @ and # cannot normally be used in identifiers.
  5. Keywords cannot be used as variable names.
  6. C variable names are case-sensitive.

Valid Names

age
studentName
student_name
marks1
_total

Invalid Names

1age
student-name
student name
float
total@marks

3.9 Case Sensitivity

C is case-sensitive. Therefore, the following are different identifiers: 

age
Age
AGE
aGe

Each of these names is considered different by the compiler.

3.10 Variables and Data Types

A variable is declared with a data type. The data type tells the compiler what kind of value the variable is intended to represent.

Type Typical Use Example
char Character data char grade = 'A';
int Integer values int age = 20;
float Single-precision floating-point values float price = 25.5f;
double Double-precision floating-point values double pi = 3.14159;

3.12 Program Example: Integer Variable

#include <stdio.h>

int main()
{
    int age = 20;

    printf("Age = %d", age);

    return 0;
}

Output

Age = 20

The variable age stores the value 20.

3.13 Program Example: Changing a Variable

#include <stdio.h>

int main()
{
    int number = 10;

    printf("Before = %d\n", number);

    number = 50;

    printf("After = %d", number);

    return 0;
}

Output

Before = 10
After = 50

The assignment statement changes the value stored in number.

3.14 Program Example: Multiple Variables

#include <stdio.h>

int main()
{
    int a = 10;
    int b = 20;
    int sum;

    sum = a + b;

    printf("A = %d\n", a);
    printf("B = %d\n", b);
    printf("Sum = %d", sum);

    return 0;
}

Output

A = 10
B = 20
Sum = 30

3.15 Program Example: Different Variable Types

#include <stdio.h>

int main()
{
    int age = 18;
    float height = 5.8f;
    char grade = 'A';

    printf("Age = %d\n", age);
    printf("Height = %.1f\n", height);
    printf("Grade = %c", grade);

    return 0;
}

Output

Age = 18
Height = 5.8
Grade = A

3.16 Variables with User Input

Variables are frequently used to store values entered by the user. 

#include <stdio.h>

int main()
{
    int age;

    printf("Enter your age: ");
    scanf("%d", &age);

    printf("Your age is %d", age);

    return 0;
}

The scanf() function stores the entered integer in the variable age.

3.17 Local and Global Variables

Local Variable

A variable declared inside a function or block generally has local scope and can be accessed within its applicable region. 

#include <stdio.h>

int main()
{
    int number = 10;

    printf("%d", number);

    return 0;
}

Here, number is local to the main() function.

Global Variable

A variable declared outside all functions has file scope and is commonly called a global variable. 

#include <stdio.h>

int number = 100;

int main()
{
    printf("%d", number);

    return 0;
}

The global variable number is declared outside main().
