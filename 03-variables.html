Chapter 3: Variables in C

Learn how variables store data, how to declare and initialize them, and how variables are used in C programs.

🎯 Learning Objectives

After completing this chapter, you will be able to:

  • Understand what a variable is.
  • Understand why variables are required in programs.
  • Declare variables correctly.
  • Initialize variables.
  • Assign and modify values.
  • Understand variable naming rules.
  • Understand local and global variables.
  • Use variables in C programs.
  • Avoid common variable-related errors.

3.1 Introduction to Variables

A variable is a named memory location used to store a value that can change while a program is running.

For example, a program that calculates the total marks of a student needs a place to store marks. A variable can provide that storage. 

int marks = 85;

In this statement, marks is a variable that stores the integer value 85.

3.2 Variable Declaration

A variable should be declared with a data type before it is used. 

int age;
float salary;
char grade;
double distance;

3.3 Variable Initialization

Initialization means assigning an initial value to a variable when it is declared. 

int age = 20;

float marks = 85.5;

char grade = 'A';

3.4 Assigning Values

A value can be assigned or changed after the variable has been declared. 

int number;

number = 10;

number = 20;

The final value stored in number is 20.

3.5 Variable Naming Rules

  • A variable name can contain letters.
  • Digits can be used, but the name should not begin with a digit.
  • Underscore can be used.
  • Spaces are not allowed.
  • C keywords cannot be used as variable names.
  • C variable names are case-sensitive. 
int studentAge;
int student_age;
int marks1;

3.6 Local Variables

A local variable is declared inside a function or block and can normally be used within that scope. 

#include <stdio.h>

int main()
{
    int age = 20;

    printf("%d", age);

    return 0;
}

3.7 Global Variables

A global variable is declared outside functions and can be accessed according to its scope. 

#include <stdio.h>

int number = 100;

int main()
{
    printf("%d", number);

    return 0;
}

3.8 Example Program 

#include <stdio.h>

int main()
{
    int age = 20;
    float marks = 85.5;
    char grade = 'A';

    printf("Age = %d\n", age);
    printf("Marks = %.2f\n", marks);
    printf("Grade = %c\n", grade);

    return 0;
}

Output 

Age = 20
Marks = 85.50
Grade = A

📝 Chapter Summary

Variables are used to store data in C programs. Every variable has a data type and a name. Variables can be declared, initialized and modified during program execution.
