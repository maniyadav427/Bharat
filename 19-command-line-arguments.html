Chapter 19: Command Line Arguments in C

Learn how values can be supplied to a C program when it is started from a command-line environment using argc and argv.

19.1 Introduction to Command Line Arguments

A command line argument is a value supplied to a program when the program is started from a command-line environment.

Command line arguments allow users to provide information to a program without entering it after the program has already started.

Simple Example

program Hello

In this example, Hello is supplied to the program as a command line argument.

Simple Definition:

Command line arguments are values supplied to a program when it is executed from the command line.

19.2 Why Are Command Line Arguments Needed?

Command line arguments are useful when a program needs input immediately when it starts.

  • To provide input when starting a program.
  • To avoid repeated keyboard input.
  • To automate program execution.
  • To pass filenames to programs.
  • To pass configuration options.
  • To create command-line utilities.
  • To process multiple values efficiently.

19.3 main() Function with Arguments

A C program can define main() with parameters that receive command line information. 

int main(int argc, char *argv[])
{
    /* Program statements */
}

The two commonly used parameters are:

  • argc — argument count
  • argv — argument vector

19.4 What is argc?

argc stands for argument count. It contains the number of command-line arguments available to the program.

The program name is normally included in this count.

Example

program Hello World

Here, there are normally three argument strings:

  1. program
  2. Hello
  3. World

Therefore: 

argc = 3

19.5 What is argv?

argv stands for argument vector. It provides access to the individual command line argument strings.

It is commonly declared as: 

char *argv[]

Each element of argv points to a null-terminated character string.

19.6 Understanding argc and argv

Command: program Hello World | v argc = 3 argv | +-------+-------+-------+ | | | | v v v v argv[0] argv[1] argv[2] argv[3] | | | | program Hello World NULL

The exact text stored in argv[0] depends on how the program was invoked, but it commonly represents the program name or invocation path.

    {

19.11 Syntax of Command Line Arguments

int main(int argc, char *argv[])
{
    statements;
}

Another equivalent form is: 

int main(int argc, char **argv)
{
    statements;
}

Both forms represent an array of pointers to character strings.

19.12 Meaning of char *argv[]

The declaration: 

char *argv[]

means that argv is an array whose elements are pointers to characters.

Each element points to a null-terminated string.

argv | v +-------+-------+-------+ | | | | v v v v char* char* char* NULL | | | v v v "program" "Hello" "World"

19.13 Argument Indexing

Command line arguments are accessed using array indexing. 

argv[0]
argv[1]
argv[2]
argv[3]

The first element, argv[0], normally refers to the program invocation.

User-provided arguments generally begin at argv[1].

19.19 Strings and Command Line Arguments

Command line arguments are received as strings. 

argv[1]

does not directly represent an integer, even if the user types: 

25

It is received as a character string.

Important: Command line arguments are text. If numerical calculations are required, the strings must be converted to numeric types.

19.20 Converting a String to Integer

The atoi() function can convert a string to an integer.

It is declared in stdlib.h. 

#include <stdlib.h>

int number = atoi(argv[1]);
atoi() provides limited error reporting. For robust programs, strtol() is generally preferred because it can report conversion errors.

19.21 Program: Add Two Numbers

#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[])
{
    if (argc != 3)
    {
        printf("Usage: program number1 number2");
        return 1;
    }

    int a = atoi(argv[1]);
    int b = atoi(argv[2]);

    printf("Sum = %d", a + b);

    return 0;
}

Command

program 10 20

Output

Sum = 30

19.22 Using strtol() for Safer Integer Conversion

The strtol() function provides more control over integer conversion and error checking. 

#include <stdio.h>
#include <stdlib.h>
#include <errno.h>
#include <limits.h>

int main(int argc, char *argv[])
{
    char *end;
    long value;

    if (argc != 2)
    {
        printf("Usage: program number");
        return 1;
    }

    errno = 0;

    value = strtol(argv[1], &end, 10);

    if (errno != 0 ||
        end == argv[1] ||
        *end != '\0' ||
        value < INT_MIN ||
        value > INT_MAX)
    {
        printf("Invalid integer");
        return 1;
    }

    printf("Number = %ld", value);

    return 0;
}

19.23 Command Line Arguments with Spaces

Arguments are normally separated by spaces. If a single argument needs to contain spaces, the command-line shell generally requires quotation marks.

Example

program "Hello World"

In this case, Hello World is treated as one argument by typical command-line shells.

19.24 argc and argv Relationship

argc | v Number of argument strings | v argv | v +-----------------------+ | Array of string | | pointers | +-----------------------+ | +--------+--------+ | | | v v v argv[0] argv[1] argv[2]

19.25 Important Rules

  • argc represents the number of argument strings.
  • argv provides access to the argument strings.
  • argv[0] normally identifies the program invocation.
  • User arguments normally begin at argv[1].
  • argv[argc] is a null pointer.
  • Command line arguments are strings.
  • Numeric arguments need conversion before arithmetic.

19.32 Program: Simple Calculator

#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[])
{
    if (argc != 4)
    {
        printf("Usage: program number operator number");
        return 1;
    }

    int a = atoi(argv[1]);
    int b = atoi(argv[3]);
    char op = argv[2][0];

    switch (op)
    {
        case '+':
            printf("Result = %d", a + b);
            break;

        case '-':
            printf("Result = %d", a - b);
            break;

        case '*':
            printf("Result = %d", a * b);
            break;

        case '/':
            if (b == 0)
            {
                printf("Division by zero is not allowed.");
            }
            else
            {
                printf("Result = %d", a / b);
            }
            break;

        default:
            printf("Invalid operator");
    }

    return 0;
}

Command

program 10 + 5

Output

Result = 15

19.33 Program: Search an Argument

#include <stdio.h>

int main(int argc, char *argv[])
{

    {
        printf("No arguments supplied.");
        return 0;

    char target[100];

    printf("Enter value to search: ");
    scanf("%99s", target);

    for (int i = 1; i < argc; i++)
    {

19.37 Command Line Arguments and Loops

Since argv behaves like an array of strings, loops can be used to process an unknown number of arguments. 

for (int i = 1; i < argc; i++)
{
    printf("%s\n", argv[i]);
}
The loop usually starts at 1 when processing user-supplied arguments because argv[0] normally represents the program invocation.

19.38 Command Line Arguments and Strings

Since command line arguments are strings, functions from string.h can be used to compare and manipulate them. 

#include <string.h>

if (strcmp(argv[1], "hello") == 0)
{
    printf("Hello command received");
}

19.39 Command Line Arguments and Files

Command line arguments are commonly used to provide file names to programs. 

#include <stdio.h>

int main(int argc, char *argv[])
{
    FILE *fp;

    if (argc != 2)
    {
        printf("Usage: program filename");
        return 1;
    }

    fp = fopen(argv[1], "r");

    if (fp == NULL)
    {
        printf("Unable to open file");
        return 1;
    }

    printf("File opened successfully");

    fclose(fp);

    return 0;
}

Command

program data.txt

19.40 Command Line Options

Command line programs often use arguments beginning with symbols such as - or -- to represent options.

Example

program --help

The program can inspect argv[1] and decide what action should be performed.

19.41 Advantages of Command Line Arguments

  • Input can be provided when the program starts.
  • Useful for automation and scripting.
  • Suitable for command-line utilities.
  • Reduces interactive input for repeated tasks.
  • Can pass filenames and options easily.
  • Supports batch processing.
  • Makes programs convenient to use from scripts.

19.42 Disadvantages of Command Line Arguments

  • Users must understand the correct command syntax.
  • Arguments are initially strings.
  • Invalid input must be handled by the program.
  • Complex command syntax can become difficult to manage.
  • Programs should not assume that required arguments were supplied.

19.43 Common Errors

❌ Error 1: Accessing argv[1] Without Checking argc

printf("%s", argv[1]);

If no user argument was supplied, accessing argv[1] is invalid.

❌ Error 2: Treating String as Integer

int x = argv[1];

argv[1] is a string pointer, not an integer. Convert it using an appropriate conversion function.

❌ Error 3: Wrong Argument Count

program 10 20

If the program expects exactly two user arguments, it should verify that argc == 3.

❌ Error 4: Invalid Numeric Input

Functions such as atoi() do not provide strong error reporting. For robust applications, use strtol(), strtoll(), strtod() or another suitable conversion function with proper validation.

19.44 Best Practices

  1. Always validate the value of argc before accessing argv.
  2. Remember that argv values are strings.
  3. Validate numeric conversions.
  4. Display a usage message when arguments are missing or incorrect.
  5. Use descriptive command-line options.
  6. Handle invalid input gracefully.
  7. Avoid assumptions about argv[0].
  8. Use loops when processing an arbitrary number of arguments.

19.45 Usage Message

19.51 Complete Working Example

#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[])
{
    if (argc != 3)
    {
        printf("Usage: program number1 number2\n");
        return 1;
    }

    int a = atoi(argv[1]);
    int b = atoi(argv[2]);

    printf("First number  = %d\n", a);
    printf("Second number = %d\n", b);
    printf("Sum           = %d\n", a + b);
    printf("Difference    = %d\n", a - b);
    printf("Product       = %d\n", a * b);

    if (b != 0)
    {
        printf("Quotient      = %d\n", a / b);
    }
    else
    {
        printf("Quotient      = undefined\n");
    }

    return 0;
}

19.53 Summary

Command line arguments allow a C program to receive input when the program is started.

The main() function can receive two commonly used parameters: argc and argv.

argc stores the number of argument strings, while argv provides access to those strings.

Command line arguments are initially represented as null-terminated character strings. Numeric arguments must be converted before mathematical operations are performed.

Easy Formula to Remember:

argc → Count
argv → Values
argv[0] → Program
argv[1] → First User Argument
