4.1 Introduction to Data Types

A data type tells the C compiler what kind of value a variable is intended to store and how operations on that value should be interpreted.

For example, an age is normally represented using an integer, while a temperature may require a floating-point type. 

int age = 20;

float temperature = 36.5f;

char grade = 'A';

In these declarations, int, float and char are data types.

Simple definition: A data type describes the kind of data that a variable, expression or object can represent.

4.2 Historical Background

C was designed with efficiency and relatively direct control over computer resources in mind. Data types are an important part of this design because they help the compiler determine how values should be represented and manipulated.

C provides several fundamental arithmetic and character types, along with ways to construct more complex types such as arrays, pointers, structures and unions.

Different C implementations can have different sizes for some types, so programmers should not assume that every integer or floating-point type has exactly the same size on every platform.

4.3 Categories of C Data Types

C DATA TYPES | +--------------+--------------+ | | | Basic Derived User-defined | | | int, char arrays struct float, double pointers union functions enum typedef

C data types can be broadly organized into fundamental types, derived types and user-defined types. The language also provides the void type for situations where no value is represented.

4.4 Basic Data Types

Data Type Typical Purpose Example
char Character and small integer values char grade = 'A';
int Integer values int age = 20;
float Single-precision floating-point values float price = 25.5f;
double Double-precision floating-point values double pi = 3.14159;
void No value void function(void);
Exact sizes and ranges depend on the C implementation. Use sizeof and the appropriate limits from standard headers when portability matters.

4.5 Integer Data Type

The int type is commonly used for whole-number values. 

int age = 21;
int marks = 95;
int temperature = -5;

Integer variables can represent positive numbers, negative numbers and zero, subject to their range.

Example

#include <stdio.h>

int main()
{
    int number = 100;

    printf("Number = %d", number);

    return 0;
}

Output

Number = 100

4.6 Character Data Type

The char type is commonly used to store a character, such as a letter or digit character. 

char grade = 'A';
char symbol = '#';
char digit = '7';

Character constants are written using single quotation marks.

Remember: 'A' is a character constant, while "A" is a string literal.

4.7 Float Data Type

The float type represents single-precision floating-point values. 

float price = 99.50f;
float temperature = 36.5f;

The suffix f can be used to indicate a floating-point constant of type float.

4.8 Double Data Type

The double type is used for double-precision floating-point values and generally provides more precision than float. 

double pi = 3.141592653589793;

It is commonly used when greater floating-point precision is useful.

4.9 Void Data Type

The void type indicates that no value is represented in a particular context.

A common use is a function that does not return a value. 

void display()
{
    printf("Hello");
}

Here, display() performs an action but does not return a value to its caller.

4.10 Signed and Unsigned Types

Integer types can be qualified with signed or unsigned.

Signed

A signed integer type can represent negative values, zero and positive values. 

signed int temperature = -10;

Unsigned

An unsigned integer type represents non-negative values. 

unsigned int count = 100;
Type Can Represent Negative Values?
signed int Yes
unsigned int No

4.11 Short and Long Integer Types

C provides type modifiers such as short and long to provide integer types with different minimum ranges. 

short int smallNumber;

long int largeNumber;

The exact sizes are implementation-defined, so portable programs should use the limits defined by the implementation rather than assuming a particular number of bytes.

4.12 sizeof Operator

The sizeof operator can be used to determine the size, in bytes, of a type or expression. 

#include <stdio.h>

int main()
{
    printf("char   = %zu bytes\n", sizeof(char));
    printf("int    = %zu bytes\n", sizeof(int));
    printf("float  = %zu bytes\n", sizeof(float));
    printf("double = %zu bytes\n", sizeof(double));

    return 0;
}

The actual output depends on the compiler and platform.

4.13 Data Type Comparison

Type Typical Data Example Common Format Specifier
char Character 'A' %c
int Integer 100 %d
unsigned int Non-negative integer 100 %u
float Floating-point value 3.14f %f
double Double-precision floating-point value 3.14159 %f
Format specifiers are context-dependent. For example, printf() and scanf() do not always use exactly the same specifier rules for every type.

4.14 Derived Data Types

Derived types are constructed from other types.

1. Arrays

int marks[5];

An array stores multiple elements of the same type.

2. Pointers

int *ptr;

A pointer stores an address associated with an object or function according to the applicable pointer type.

3. Functions

int add(int a, int b);

Function declarations describe functions and their return and parameter types.

4.15 User-Defined Types

Structure

A structure groups related members that may have different types. 

struct Student
{
    int age;
    char grade;
};

Union

A union provides several members that share the same storage. 

union Data
{
    int number;
    float value;
};

Enumeration

An enumeration defines a set of named integer constants. 

enum Day
{
    MONDAY,
    TUESDAY,
    WEDNESDAY
};

typedef

typedef creates an alternative name for an existing type. 

typedef unsigned int uint;

4.17 Program Example: Basic Data Types

#include <stdio.h>

int main()
{
    int age = 20;
    float height = 5.8f;
    double pi = 3.14159;
    char grade = 'A';

    printf("Age = %d\n", age);
    printf("Height = %.1f\n", height);
    printf("Pi = %.5f\n", pi);
    printf("Grade = %c\n", grade);

    return 0;
}

Output

Age = 20
Height = 5.8
Pi = 3.14159
Grade = A
