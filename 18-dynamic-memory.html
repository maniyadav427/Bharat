Chapter 18: Dynamic Memory Allocation in C

Learn how C programs can allocate, resize and release memory dynamically during program execution using malloc(), calloc(), realloc() and free().

18.1 Introduction to Dynamic Memory Allocation

Memory is required by a C program to store variables, arrays, structures and other data while the program is running.

In many programs, the required amount of memory is known before execution. However, sometimes the amount of memory required depends on information available only while the program is running.

C provides dynamic memory allocation functions that allow a program to request memory during execution.

Simple Definition:

Dynamic memory allocation is the process of obtaining and releasing memory during program execution.

18.2 Why is Dynamic Memory Allocation Needed?

Dynamic memory allocation is useful when the required memory size is not known in advance.

  • To allocate memory according to user input.
  • To avoid allocating unnecessarily large fixed arrays.
  • To create dynamic data structures.
  • To resize memory when requirements change.
  • To efficiently manage available memory.
  • To implement linked lists, trees and other structures.

18.3 Static Memory vs Dynamic Memory

Static / Automatic Allocation Dynamic Allocation
Size is usually determined before or at block entry. Memory is requested during execution.
Uses ordinary variables and arrays. Uses allocation functions.
Lifetime follows its storage duration. Memory remains allocated until released.
Simple to use. Requires careful memory management.
Less control over runtime size. Flexible runtime size.

The functions used for dynamic memory allocation are declared in the standard header file: 

#include <stdlib.h>

Functions such as malloc(), calloc(), realloc() and free() are declared in stdlib.h.

18.6 Main Dynamic Memory Functions

Function Purpose
malloc() Allocates a block of memory.
calloc() Allocates memory for multiple elements and initializes the bytes to zero.
realloc() Changes the size of an existing allocated block.
free() Releases dynamically allocated memory.

18.7 malloc() Function

The malloc() function allocates a specified number of bytes of memory.

Syntax

ptr = malloc(number_of_bytes);

In modern C, the result can be assigned directly to a suitably typed object pointer without an explicit cast.

Example

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int *ptr;

    ptr = malloc(sizeof *ptr);

    if (ptr == NULL)
    {
        printf("Memory allocation failed");
        return 1;
    }

    *ptr = 100;

    printf("Value = %d", *ptr);

    free(ptr);

    return 0;
}

Output

Value = 100

18.9 Checking malloc() Result

Memory allocation can fail. When an allocation function cannot provide the requested memory, it returns NULL. 

int *ptr;

ptr = malloc(10 * sizeof *ptr);

if (ptr == NULL)
{
    printf("Memory allocation failed");
    return 1;
}
Always check the result of a dynamic memory allocation before using the returned pointer.

18.10 sizeof Operator with Dynamic Allocation

The sizeof operator is commonly used to calculate the number of bytes needed for an object. 

int *ptr;

ptr = malloc(10 * sizeof *ptr);

This requests enough memory for 10 objects of the type pointed to by ptr.

Using sizeof *ptr can help avoid repeating the pointer's type in an allocation expression.

18.12 Dynamic Allocation of an Array

A dynamically allocated array can be created when the number of elements becomes known at runtime. 

int n;

scanf("%d", &n);

int *arr = malloc(n * sizeof *arr);

The pointer arr can then be used with normal array indexing, after checking that the allocation succeeded.

18.13 Example: Dynamic Integer Array

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int n;

    printf("Enter number of elements: ");
    scanf("%d", &n);

    if (n <= 0)
    {
        printf("Invalid size");
        return 0;
    }

    int *arr = malloc(n * sizeof *arr);

    if (arr == NULL)
    {
        printf("Memory allocation failed");
        return 1;
    }

    for (int i = 0; i < n; i++)
    {
        arr[i] = i + 1;
    }

    for (int i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    free(arr);

    return 0;
}

Example Output

Enter number of elements: 5
1 2 3 4 5

18.14 calloc() Function

The calloc() function allocates memory for a specified number of elements.

Syntax

ptr = calloc(number_of_elements, size_of_each_element);

The allocated bytes are initialized to zero.

Example

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int *arr;

    arr = calloc(5, sizeof *arr);

    if (arr == NULL)
    {
        printf("Memory allocation failed");
        return 1;
    }

    for (int i = 0; i < 5; i++)
    {
        printf("%d ", arr[i]);
    }

    free(arr);

    return 0;
}

Output

0 0 0 0 0

malloc() calloc()

18.17 realloc() Function

The realloc() function changes the size of an existing dynamically allocated memory block.

Syntax

new_ptr = realloc(ptr, new_size);

The returned pointer may be different from the original pointer because the memory block may need to be moved.

18.18 Example of realloc()

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int *arr;

    arr = malloc(3 * sizeof *arr);

    if (arr == NULL)
    {
        printf("Memory allocation failed");
        return 1;
    }

    arr[0] = 10;
    arr[1] = 20;
    arr[2] = 30;

    int *temp = realloc(arr, 5 * sizeof *arr);

    if (temp == NULL)
    {
        free(arr);
        printf("Memory reallocation failed");
        return 1;
    }

    arr = temp;

    arr[3] = 40;
    arr[4] = 50;

    for (int i = 0; i < 5; i++)
    {
        printf("%d ", arr[i]);
    }

    free(arr);

    return 0;
}

Output

10 20 30 40 50

18.19 Safe Use of realloc()

It is good practice to assign the result of realloc() to a temporary pointer. 

int *temp;

temp = realloc(arr, new_size);

if (temp != NULL)
{
    arr = temp;
}
else
{
    /* Original arr is still valid here. */
}
Do not overwrite the only pointer to an allocated block with realloc() before checking whether the operation succeeded.

18.20 free() Function

The free() function releases memory previously allocated by malloc(), calloc() or realloc().

Syntax

free(ptr);

Example

int *ptr;

ptr = malloc(sizeof *ptr);

if (ptr != NULL)
{
    *ptr = 100;

    printf("%d", *ptr);

    free(ptr);
    ptr = NULL;
}

18.21 Why is free() Important?

Dynamically allocated memory is not automatically released merely because the pointer variable goes out of scope. The program should release memory it no longer needs.

  • Prevents memory leaks.
  • Makes memory available for future allocations.
  • Improves resource management.
  • Helps long-running programs remain stable.

18.22 Memory Leak

A memory leak occurs when dynamically allocated memory is no longer reachable by the program but has not been released.

Example of a Leak

int *ptr;

ptr = malloc(100 * sizeof *ptr);

/* Memory is never freed. */

If the program loses access to ptr without calling free(), the allocated memory cannot be reused by the program during that execution.

18.23 Dangling Pointer

A dangling pointer is a pointer that refers to memory that has already been released or is otherwise no longer valid.

Example

int *ptr;

ptr = malloc(sizeof *ptr);

free(ptr);

/* ptr is now a dangling pointer. */

A common practice after freeing a pointer is: 

free(ptr);
ptr = NULL;

18.24 NULL Pointer After free()

Setting a pointer to NULL after freeing its memory can help avoid accidentally using the old address. 

free(ptr);
ptr = NULL;
A NULL pointer does not point to a valid object. It should not be dereferenced.

18.27 Program: Dynamic Array Sum

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int n;
    int sum = 0;

    printf("Enter number of elements: ");
    scanf("%d", &n);

    if (n <= 0)
    {
        printf("Invalid size");
        return 0;
    }

    int *arr = malloc(n * sizeof *arr);

    if (arr == NULL)
    {
        printf("Memory allocation failed");
        return 1;

18.37 Allocation Failure

Allocation functions may fail to provide the requested memory. A failed allocation returns NULL. 

int *ptr = malloc(1000000000 * sizeof *ptr);

if (ptr == NULL)
{
    printf("Allocation failed");
}

Programs should handle allocation failure rather than dereferencing a NULL pointer.

18.38 Integer Overflow in Allocation Sizes

When calculating the size of an allocation, arithmetic overflow can result in requesting less memory than intended.

For example, a multiplication such as count * sizeof *ptr should be considered carefully when count comes from untrusted or very large input.

Always validate sizes before performing large allocation calculations.

18.39 Zero-Size Allocation Requests

A request with a size of zero has implementation-defined allocation behavior under the C standard and should not be treated as an ordinary usable object.

Validate the requested number of elements before allocating memory for an array.

18.40 Advantages of Dynamic Memory Allocation

  • Memory can be allocated according to runtime needs.
  • Supports variable-size data structures.
  • Useful for linked lists, trees and graphs.
  • Allows dynamic arrays.
  • Memory can be released when no longer needed.
  • Supports flexible program designs.

18.41 Disadvantages of Dynamic Memory Allocation

  • Memory management is the programmer's responsibility.
  • Incorrect use can cause memory leaks.
  • Incorrect pointer use can cause undefined behavior.
  • Dangling pointers can occur.
  • Allocation can fail.
  • Memory fragmentation can affect allocation patterns.

18.42 Common Errors in Dynamic Memory Allocation

❌ Error 1: Not Checking Allocation

int *ptr = malloc(100 * sizeof *ptr);

*ptr = 10;

The allocation result should be checked before dereferencing the pointer.

❌ Error 2: Forgetting free()

int *ptr = malloc(100 * sizeof *ptr);

/* Missing free(ptr) */

This can cause a memory leak.

❌ Error 3: Using Memory After free()

free(ptr);

printf("%d", *ptr);

The pointer must not be dereferenced after the memory has been released.

❌ Error 4: Double free

free(ptr);
free(ptr);

Freeing the same allocation more than once is invalid.

❌ Error 5: Losing the Original Pointer with realloc()

ptr = realloc(ptr, new_size);

If realloc fails, the original allocation is still present but the original pointer may have been lost. Use a temporary pointer when failure needs to be handled.

18.43 Best Practices

  1. Include stdlib.h when using the allocation functions.
  2. Check allocation results for NULL.
  3. Use sizeof to calculate object sizes.
  4. Free every allocation that is no longer required.
  5. Do not access memory after it has been freed.
  6. Set pointers to NULL after freeing when appropriate.
  7. Use a temporary pointer when safely handling realloc().
  8. Validate user-provided sizes.
  9. Avoid integer overflow in allocation calculations.
  10. Keep ownership of allocated memory clear in larger programs.

18.45 Dynamic Memory for Linked List Nodes

Dynamic memory allocation is essential when creating nodes for linked data structures. 

struct Node
{
    int data;
    struct Node *next;
};

struct Node *newNode;

newNode = malloc(sizeof *newNode);

if (newNode != NULL)
{
    newNode->data = 10;
    newNode->next = NULL;
}

Each node can be created dynamically when the program needs it.

18.52 Summary

Dynamic memory allocation allows a C program to request memory during execution instead of relying only on fixed storage sizes.

The four most important dynamic memory functions are malloc(), calloc(), realloc() and free().

Dynamic memory is particularly important for data structures whose size changes while the program is running.

Easy Formula to Remember:

Allocate → Check → Use → Resize if needed → Free

    To avoid losing the original allocation if realloc() fails.
  12. Why is dynamic memory useful?
    It allows memory requirements to be determined and changed at runtime.

18.57 Final Chapter Summary 📚

Dynamic memory allocation provides flexibility for programs that need memory whose size is determined during execution.

The four essential functions are malloc(), calloc(), realloc() and free().

Proper dynamic memory management requires checking allocation results, using memory only while it is valid, releasing memory when it is no longer needed and avoiding memory leaks, dangling pointers and double frees.
