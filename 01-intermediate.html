1.1 Introduction to Advanced Functions

A function is a named block of C code that performs a particular task. Functions are one of the most important mechanisms for organizing large programs.

In beginner-level C programming, functions are often used simply to divide a program into smaller parts. At the intermediate level, functions can also work with pointers, arrays, structures and recursive calls.

Simple Definition:

A function is a reusable block of code that performs a specific task and can receive input through parameters and optionally return a result.

1.2 Why Functions Are Important

  • Functions reduce code repetition.
  • Functions divide a large problem into smaller problems.
  • Functions improve code readability.
  • Functions make debugging easier.
  • Functions improve code reuse.
  • Functions allow independent testing of program parts.
  • Functions are essential for structured programming.

1.3 Basic Structure of a Function

return_type function_name(parameters)
{
    statements;

    return value;
}
Part Purpose
return_type Specifies the type of result returned by the function.
function_name Name used to call the function.
parameters Values received by the function.
function body Contains statements executed by the function.
return Sends a result back to the caller when required.

1.4 Function Prototype

A function prototype tells the compiler the function's name, return type and parameter types before the function is called.

Syntax

return_type function_name(parameter_types);

Example

int add(int, int);

The prototype allows the compiler to check calls to the function more accurately.

1.5 Function Prototype Example

#include <stdio.h>

int add(int, int);

int main()
{
    int result;

    result = add(10, 20);

    printf("Result = %d", result);

    return 0;
}

int add(int a, int b)
{
    return a + b;
}

Output

Result = 30

1.6 Function Call

A function call transfers control to the function and supplies any required arguments. 

result = add(10, 20);

Here, the values 10 and 20 are passed to the parameters of the add() function.

1.7 Function Parameters and Arguments

Term Meaning
Parameter Variable declared in a function definition.
Argument Actual value or expression supplied during a call.

Example

int add(int a, int b)
{
    return a + b;
}

add(10, 20);

Here, a and b are parameters, while 10 and 20 are arguments.

1.8 Call by Value

In C, ordinary function parameters receive copies of the values supplied by the caller. This is commonly described as call by value.

Changes made to the parameter inside the function do not directly change the original variable in the caller.

Example

#include <stdio.h>

void change(int x)
{
    x = 100;
}

int main()
{
    int a = 10;

    change(a);

    printf("a = %d", a);

    return 0;
}

Output

a = 10

1.9 Call by Value Flow

main() | | a = 10 v change(a) | v x receives 10 | v x = 100 | v Function ends | v a is still 10
C does not have a separate built-in "call by reference" parameter mechanism. Reference-like modification is commonly achieved by passing pointers.

1.10 Call by Reference Using Pointers

A pointer can be passed to a function so that the function can access and modify the original object through its address.

Example

#include <stdio.h>

void change(int *x)
{
    *x = 100;
}

int main()
{
    int a = 10;

    change(&a);

    printf("a = %d", a);

    return 0;
}

Output

a = 100

1.11 How Pointer Parameters Work

main() | v a = 10 | &a | v change(&a) | v x stores address | v *x = 100 | v Original a = 100

1.12 Swap Two Numbers Using Pointers

#include <stdio.h>

void swap(int *a, int *b)
{
    int temp;

    temp = *a;
    *a = *b;
    *b = temp;
}

int main()
{
    int x = 10;
    int y = 20;

    printf("Before swap: x = %d, y = %d\n", x, y);

    swap(&x, &y);

    printf("After swap: x = %d, y = %d", x, y);

    return 0;
}

Output

Before swap: x = 10, y = 20
After swap: x = 20, y = 10

1.25 Recursion

Recursion is a programming technique in which a function calls itself to solve a problem.

Simple Definition:

Recursion is the process in which a function calls itself with a smaller or simpler version of the problem until a stopping condition is reached.

1.26 Basic Structure of Recursion

return_type function()
{
    if (base_condition)
    {
        return result;
    }

    return function();
}

A correct recursive function normally needs:

  1. A base case.
  2. A recursive case.
  3. Progress toward the base case.

1.27 Base Case

The base case is the condition that stops further recursive calls. 

if (n == 0)
{
    return 1;
}
Without an appropriate base case, recursion may continue until the program exhausts available call-stack space.

1.28 Recursive Case

The recursive case is the part of the function that calls the same function again with a smaller or simpler problem. 

return n * factorial(n - 1);

Here, factorial() calls itself with n - 1.

1.29 Recursion Flow

START | v Call Function | v Base Case? / \ Yes No | | v v Return Recursive Result Call | v Smaller Problem | +-----> Repeat | v END

1.30 Simple Recursive Program

#include <stdio.h>

void countDown(int n)
{
    if (n == 0)
    {
        return;
    }

    printf("%d ", n);

    countDown(n - 1);
}

int main()
{
    countDown(5);

    return 0;
}

Output

5 4 3 2 1

1.31 Recursive Call Trace

countDown(5)
    |
    +-- countDown(4)
          |
          +-- countDown(3)
                |
                +-- countDown(2)
                      |
                      +-- countDown(1)
                            |
                            +-- countDown(0)
                                  |
                                  +-- return

1.32 Factorial Using Recursion

The factorial of a non-negative integer n is: 

n! = n × (n - 1) × (n - 2) × ... × 1

Mathematically: 

n! = n × (n - 1)!

The base case is: 

0! = 1

1.33 Factorial Program Using Recursion

#include <stdio.h>

unsigned long long factorial(int n)
{
    if (n == 0)
    {
        return 1;
    }

    return (unsigned long long)n * factorial(n - 1);
}

int main()
{
    int n;

    printf("Enter a number: ");
    scanf("%d", &n);

    if (n < 0)
    {
        printf("Factorial is not defined for negative integers.");
    }
    else
    {
        printf("Factorial = %llu", factorial(n));
    }

    return 0;
}

Output

Enter a number: 5
Factorial = 120

1.34 Factorial Recursion Trace

factorial(5) | v 5 * factorial(4) | v 4 * factorial(3) | v 3 * factorial(2) | v 2 * factorial(1) | v 1 * factorial(0) | v 1 | v 2 | v 6 | v 24 | v 120

1.35 Fibonacci Series Using Recursion

The Fibonacci sequence begins: 

0 1 1 2 3 5 8 13 21 ...

A common mathematical definition is: 

F(0) = 0
F(1) = 1

F(n) = F(n - 1) + F(n - 2)

1.36 Fibonacci Recursive Program

#include <stdio.h>

int fibonacci(int n)
{
    if (n == 0)
    {
        return 0;
    }

    if (n == 1)
    {
        return 1;
    }

    return fibonacci(n - 1) + fibonacci(n - 2);
}

int main()
{
    int n;

    printf("Enter number of terms: ");
    scanf("%d", &n);

    for (int i = 0; i < n; i++)
    {
        printf("%d ", fibonacci(i));
    }

    return 0;
}

Output

Enter number of terms: 7
0 1 1 2 3 5 8

1.37 Fibonacci Recursion Tree

fibonacci(4) / \ / \ fibonacci(3) fibonacci(2) / \ / \ / \ / \ fib(2) fib(1) fib(1) fib(0) / \ fib(1) fib(0)

This shows why the simple recursive Fibonacci algorithm performs many repeated calculations.

1.38 GCD Using Recursion

The greatest common divisor of two integers can be computed using the Euclidean algorithm. 

gcd(a, b) = gcd(b, a % b)

The base case is reached when b becomes zero: 

gcd(a, 0) = a

1.39 GCD Recursive Program

#include <stdio.h>

int gcd(int a, int b)
{
    if (b == 0)
    {
        return a;
    }

    return gcd(b, a % b);
}

int main()
{
    int a, b;

    printf("Enter two numbers: ");
    scanf("%d %d", &a, &b);

    printf("GCD = %d", gcd(a, b));

    return 0;
}

Output

Enter two numbers: 48 18
GCD = 6

1.40 Recursive GCD Trace

gcd(48,18) | v gcd(18,12) | v gcd(12,6) | v gcd(6,0) | v 6

1.41 Power Using Recursion

A simple recursive definition for positive integer exponent is: 

power(x, n) = x × power(x, n - 1)

With the base case: 

power(x, 0) = 1

1.42 Recursive Power Program

#include <stdio.h>

long long power(int base, int exponent)
{
    if (exponent == 0)
    {
        return 1;
    }

    return base * power(base, exponent - 1);
}

int main()
{
    int base;
    int exponent;

    printf("Enter base and exponent: ");
    scanf("%d %d", &base, &exponent);

    if (exponent < 0)
    {
        printf("This example expects a non-negative exponent.");
    }
    else
    {
        printf("Result = %lld",
               power(base, exponent));
    }

    return 0;
}

Output

Enter base and exponent: 2 5
Result = 32

1.49 Direct and Indirect Recursion

Direct Recursion

A function directly calls itself. 

void fun()
{
    fun();
}

Indirect Recursion

One function calls another function, which eventually calls the first function. 

void A()
{
    B();
}

void B()
{
    A();
}

1.50 Direct vs Indirect Recursion

Feature Direct Recursion Indirect Recursion
Function calls itself Yes Not directly
Number of functions involved Usually one Two or more
Example factorial() A() → B() → A()

1.51 Recursion and Stack Memory

Every active function call needs information such as parameters, local variables and return information. This information is commonly maintained using the call stack.

Recursive calls therefore consume stack space while they are active.

factorial(4) | v factorial(3) | v factorial(2) | v factorial(1) | v factorial(0) Stack grows downward until the base case is reached.

1.52 Recursion Unwinding

After reaching the base case, recursive calls return in the reverse order in which they were created.

CALLING PHASE fun(4) | fun(3) | fun(2) | fun(1) | fun(0) RETURNING PHASE fun(0) | fun(1) | fun(2) | fun(3) | fun(4)

1.53 Recursion vs Iteration

Feature Recursion Iteration
Technique Function calls itself. Uses loops such as for or while.
Memory Uses call-stack space for active calls. Usually requires less call-stack overhead.
Code Can be concise for recursive problems. Often straightforward for repetitive tasks.
Risk Deep recursion can exhaust stack space. Infinite loops can occur if termination is incorrect.

1.54 Factorial: Recursion vs Loop

Recursive Version

int factorial(int n)
{
    if (n == 0)
        return 1;

    return n * factorial(n - 1);
}

Iterative Version

int factorial(int n)
{
    int result = 1;

    for (int i = 1; i <= n; i++)
    {
        result *= i;
    }

    return result;
}

1.55 Advantages of Recursion

  • Can provide a natural solution for recursively defined problems.
  • Can make some algorithms shorter and easier to express.
  • Useful for tree and graph algorithms.
  • Useful for divide-and-conquer algorithms.
  • Useful for backtracking problems.
  • Can simplify traversal of hierarchical structures.

1.56 Disadvantages of Recursion

  • Recursive calls consume call-stack memory.
  • Deep recursion can cause stack overflow.
  • Recursive code can be harder to trace for beginners.
  • Some recursive solutions repeat calculations.
  • An iterative solution may be more efficient for simple repetitive tasks.

1.57 Common Recursion Errors

❌ Missing Base Case

void fun()
{
    fun();
}

There is no condition to stop the recursion.

❌ No Progress Toward Base Case

int fun(int n)
{
    if (n == 0)
        return 0;

    return fun(n);
}

The argument does not move toward the base case.

❌ Incorrect Base Case

A wrong stopping condition can produce incorrect results or prevent termination.

1.58 Best Practices for Recursive Functions

  1. Always identify the base case first.
  2. Make sure every recursive call moves toward the base case.
  3. Keep recursive functions simple.
  4. Avoid unnecessary repeated calculations.
  5. Consider an iterative solution when recursion provides no clear benefit.
  6. Test boundary cases carefully.

1.61 Recursive Binary Search

Binary search repeatedly divides a sorted array into smaller sections. This makes it a natural example of recursion. 

#include <stdio.h>

int binarySearch(int arr[],
                 int low,
                 int high,
                 int key)
{
    if (low > high)
    {
        return -1;
    }

    int mid = low + (high - low) / 2;

    if (arr[mid] == key)
    {
        return mid;
    }

    if (key < arr[mid])
    {
        return binarySearch(arr,
                            low,
                            mid - 1,
                            key);
    }

    return binarySearch(arr,
                        mid + 1,
                        high,
                        key);
}

int main()
{
    int arr[] = {10, 20, 30, 40, 50};

    int key = 40;

    int result =
        binarySearch(arr, 0, 4, key);

    if (result == -1)
    {
        printf("Element not found");
    }
    else
    {
        printf("Element found at index %d",
               result);
    }

    return 0;
}

Output

Element found at index 3

1.62 Recursive Binary Search Flow

Sorted Array | v Find Middle | +-------+-------+ | | Key == Mid Key != Mid | | v v Return Compare Key | +--------+--------+ | | Smaller Larger | | v v Left Half Right Half | | +--------+--------+ | v Recursive Call

1.64 Recursive Maximum in Array

#include <stdio.h>

int maximum(int arr[], int n)
{
    if (n == 1)
    {
        return arr[0];
    }

    int maxRest =
        maximum(arr, n - 1);

    return arr[n - 1] > maxRest
           ? arr[n - 1]
           : maxRest;
}

int main()
{
    int arr[] = {12, 55, 8, 90, 31};

    printf("Maximum = %d",
           maximum(arr, 5));

    return 0;
}

Output

Maximum = 90

1.65 Passing a Function to Another Function

C supports function pointers. A function pointer can store the address of a function and can be passed to another function.

Example

#include <stdio.h>

int square(int x)
{
    return x * x;
}

void process(int value,
             int (*operation)(int))
{
    printf("Result = %d",
           operation(value));
}

int main()
{
    process(5, square);

    return 0;
}

Output

Result = 25

1.66 Function Pointer Concept

int (*operation)(int);
Part Meaning
int Return type of the function.
(*operation) Name of the function pointer.
(int) Function accepts one int parameter.

1.67 Function Pointers and Callbacks

Passing a function pointer to another function is commonly used to implement callback-style behavior. 

void process(int value,
             int (*operation)(int))
{
    printf("%d",
           operation(value));
}

The caller can choose which operation should be performed.

1.68 Function Scope and Local Variables

Variables declared inside a function normally have automatic storage duration and are accessible only within their scope. 

void test()
{
    int x = 10;

    printf("%d", x);
}

The variable x cannot be directly accessed from another function because its scope is local to the function block.

1.69 Static Local Variable

A local variable declared with static storage duration keeps its stored value between function calls. 

#include <stdio.h>

void counter()
{
    static int count = 0;

    count++;

    printf("%d ", count);
}

int main()
{
    counter();
    counter();
    counter();

    return 0;
}

Output

1 2 3

1.70 Static Local Variable Flow

First call | v count = 0 | v count = 1 | v Value retained Second call | v count = 1 | v count = 2 | v Value retained Third call | v count = 3

1.71 Function Design Principles

  • Give each function a clear purpose.
  • Use meaningful function names.
  • Keep functions reasonably small.
  • Use parameters to provide required input.
  • Return meaningful results.
  • Avoid unnecessary global variables.
  • Document complex algorithms.
  • Test functions independently.

Wrong argument type Can produce warnings or incorrect behavior.
Missing return A non-void function may fail to return a value on some control paths.
Wrong pointer Can cause invalid memory access.
Incorrect array size Can cause out-of-bounds access.

1.73 Common Recursion Errors

  • Missing base case.
  • Incorrect base case.
  • No progress toward the base case.
  • Excessive recursion depth.
  • Repeated calculations causing poor performance.
  • Incorrect return values.

1.74 Best Practices ⭐

  1. Declare functions clearly using prototypes.
  2. Use meaningful names for functions and parameters.
  3. Pass only the data a function actually needs.
  4. Use pointers carefully when modifying caller data.
  5. Always validate array bounds.
  6. Identify the base case before writing a recursive function.
  7. Make sure every recursive call approaches termination.
  8. Prefer iteration when recursion provides no practical advantage.

1.76 Complete Example: Menu Using Functions

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int subtract(int a, int b)
{
    return a - b;
}

int multiply(int a, int b)
{
    return a * b;
}

int main()
{
    int choice;
    int a, b;

    printf("1. Add\n");
    printf("2. Subtract\n");
    printf("3. Multiply\n");

    printf("Enter choice: ");
    scanf("%d", &choice);

    printf("Enter two numbers: ");
    scanf("%d %d", &a, &b);

    switch (choice)
    {
        case 1:
            printf("Result = %d",
                   add(a, b));
            break;

        case 2:
            printf("Result = %d",
                   subtract(a, b));
            break;

        case 3:
            printf("Result = %d",
                   multiply(a, b));
            break;

        default:
            printf("Invalid choice");
    }

    return 0;
}

2. Subtract
3. Multiply
Enter choice: 1
Enter two numbers: 10 20

1.78 Summary

Functions are fundamental building blocks for modular C programs. At the intermediate level, functions can receive pointers and arrays, return values, and work together through function pointers.

C uses pass-by-value for ordinary function parameters. Pointer parameters can be used when a function needs to access or modify an object in the caller.

Recursion occurs when a function calls itself. A recursive solution requires a base case and a recursive case that moves toward the base case.

Factorial, Fibonacci, GCD, binary search, tree traversal and divide-and-conquer algorithms are common examples where recursion can be useful.

Remember:

Function → Reusable block of code
Parameter → Variable receiving input
Argument → Actual value passed
Pointer → Can provide access to caller's object
Recursion → Function calls itself
Base Case → Stops recursion
Recursive Case → Continues with a smaller problem
