Chapter 13: Structures in C

Learn how structures allow related data of different data types to be grouped together into a single user-defined data type in C programming.

🎯 Learning Objectives

After completing this chapter, you will be able to:

  • Understand the concept of structures.
  • Understand why structures are required.
  • Declare and define structures.
  • Create structure variables.
  • Initialize structure members.
  • Access structure members.
  • Use structures with functions.
  • Understand arrays of structures.
  • Understand nested structures.
  • Use pointers with structures.

13.1 Introduction to Structures

A structure is a user-defined data type in C that allows related variables of different data types to be grouped together under one name.

For example, information about a student may contain a name, roll number, age and marks. These values can have different data types, but they belong to the same student.

A structure allows all these related values to be stored together.

Simple Definition: A structure is a user-defined data type that groups related variables of different data types under one name.

13.2 Why Are Structures Needed?

Structures are useful when a program needs to represent a real-world entity containing multiple related pieces of information.

For example, consider a student:

  • Name → Character array
  • Roll number → Integer
  • Age → Integer
  • Marks → Floating-point value

These values have different data types but all describe one student.

A structure can combine them into a single student record.

13.3 Real-World Example

Consider a student record:

STUDENT | +---------+---------+ | | | Name Roll No. Age | | | char int int | Marks | float

Instead of maintaining separate unrelated variables, a structure can group all these values together.

13.4 Structure Declaration

A structure is declared using the struct keyword.

Syntax

struct structure_name
{
    data_type member1;
    data_type member2;
    data_type member3;
};

The semicolon after the closing brace is required.

13.5 Structure Declaration Example

struct Student
{
    int rollNo;
    char name[50];
    float marks;
};

Here, Student is the structure tag.

The structure contains three members:

  • rollNo of type int
  • name of type char[50]
  • marks of type float

13.6 Declaring Structure Variables

After declaring a structure, variables of that structure type can be created. 

struct Student student1;

Here, student1 is a structure variable of type struct Student.

Multiple Structure Variables

struct Student student1, student2, student3;

Three structure variables are created in this statement.

13.7 Declaring Structure Variables with the Structure

Structure variables can also be declared immediately after the closing brace. 

struct Student
{
    int rollNo;
    char name[50];
    float marks;
} student1, student2;

Here, student1 and student2 are structure variables.

13.8 Accessing Structure Members

The dot operator . is used to access members of a structure variable.

Syntax

structure_variable.member;

Example

student1.rollNo = 101;

student1.marks = 85.5;

In these statements, rollNo and marks are accessed using the dot operator.

13.9 Basic Structure Program

#include <stdio.h>

struct Student
{
    int rollNo;
    char name[50];
    float marks;
};

int main()
{
    struct Student student1;

    student1.rollNo = 101;

    student1.marks = 85.5;

    printf("Roll Number = %d\n", student1.rollNo);

    printf("Marks = %.2f\n", student1.marks);

    return 0;
}

Output

Roll Number = 101
Marks = 85.50

13.10 Structure with a String Member

A character array can be used as a structure member to store a name or other text. 

#include <stdio.h>

struct Student
{
    int rollNo;
    char name[50];
    float marks;
};

int main()
{
    struct Student student1;

    student1.rollNo = 101;

    snprintf(student1.name,
             sizeof student1.name,
             "Rahul");

    student1.marks = 88.5;

    printf("Roll Number = %d\n", student1.rollNo);

    printf("Name = %s\n", student1.name);

    printf("Marks = %.2f\n", student1.marks);

    return 0;
}

Output

Roll Number = 101
Name = Rahul
Marks = 88.50

13.11 Structure Initialization

A structure variable can be initialized when it is declared. 

struct Student student1 =
{
    101,
    "Rahul",
    88.5
};

The values are assigned to the members in the same order in which the members are declared.

13.12 Designated Structure Initialization

C also supports designated initializers. They allow structure members to be initialized by name. 

struct Student student1 =
{
    .rollNo = 101,
    .name = "Rahul",
    .marks = 88.5
};
Designated initializers make the code easier to understand because each value is explicitly associated with a member.

13.13 Structure Memory Representation

A structure stores its members in one object. The compiler may insert padding between members to satisfy alignment requirements, so the size of a structure may be larger than the simple sum of the sizes of its members.

struct Student student1 +---------------------------+ | rollNo | +---------------------------+ | name[] | +---------------------------+ | marks | +---------------------------+ One structure object containing multiple members

The exact memory layout and size depend on the types, alignment requirements and implementation.

13.14 sizeof with Structures

The sizeof operator can be used to determine the size of a structure type or structure object. 

#include <stdio.h>

struct Student
{
    int rollNo;
    char name[50];
    float marks;
};

int main()
{
    struct Student student1;

    printf("Size = %zu bytes",
           sizeof(student1));

    return 0;
}
The exact size may vary between systems because structures can contain padding for alignment.

13.16 Advantages of Structures

  • Group related data together.
  • Allow different data types in one object.
  • Make programs easier to organize.
  • Help represent real-world entities.
  • Support arrays of records.
  • Can be passed to functions.

13.17 Array of Structures

An array of structures is a collection of structure variables of the same structure type. It is useful when storing information about multiple records such as students, employees or books.

Syntax

struct Student students[5];

The above statement creates an array that can store information for five students.

Example

#include <stdio.h>

struct Student
{
    int rollNo;
    char name[50];
    float marks;
};

int main()
{
    struct Student students[3] =
    {
        {101, "Rahul", 85.5},
        {102, "Anil", 78.5},
        {103, "Kiran", 91.0}
    };

    for (int i = 0; i < 3; i++)
    {
        printf("Roll No: %d\n", students[i].rollNo);
        printf("Name: %s\n", students[i].name);
        printf("Marks: %.2f\n\n", students[i].marks);
    }

    return 0;
}

Output

Roll No: 101
Name: Rahul
Marks: 85.50

Roll No: 102
Name: Anil
Marks: 78.50

Roll No: 103
Name: Kiran
Marks: 91.00

13.18 Accessing Members of an Array of Structures

The index operator is used to select a structure from the array, and the dot operator is then used to access its member. 

students[0].rollNo
students[0].name
students[0].marks

Here, students[0] represents the first structure object.

Similarly, students[1] represents the second structure object.

Remember: Array index selects the structure, while the dot operator selects the member.

13.19 Input for an Array of Structures

A loop can be used to read information for multiple structure variables. 

#include <stdio.h>

struct Student
{
    int rollNo;
    char name[50];
    float marks;
};

int main()
{
    struct Student students[3];

    for (int i = 0; i < 3; i++)
    {
        printf("Enter roll number: ");
        scanf("%d", &students[i].rollNo);

        printf("Enter name: ");
        scanf("%49s", students[i].name);

        printf("Enter marks: ");
        scanf("%f", &students[i].marks);
    }

    printf("\nStudent Details\n");

    for (int i = 0; i < 3; i++)
    {
        printf("\nRoll No: %d\n",
               students[i].rollNo);

        printf("Name: %s\n",
               students[i].name);

        printf("Marks: %.2f\n",
               students[i].marks);
    }

    return 0;
}
When using scanf("%s", ...) for a character array, specify a suitable field width to help prevent writing beyond the array.

13.20 Nested Structures

A structure can contain another structure as one of its members. Such a structure is called a nested structure.

Example

struct Date
{
    int day;
    int month;
    int year;
};

struct Student
{
    int rollNo;
    char name[50];
    struct Date birthDate;
};

Here, birthDate is a structure member of type struct Date.

13.21 Accessing Nested Structure Members

Nested structure members can be accessed by using the dot operator multiple times. 

student1.birthDate.day

student1.birthDate.month

student1.birthDate.year

Complete Example

#include <stdio.h>

struct Date
{
    int day;
    int month;
    int year;
};

struct Student
{
    int rollNo;
    char name[50];
    struct Date birthDate;
};

int main()
{
    struct Student student1 =
    {
        101,
        "Rahul",
        {15, 8, 2005}
    };

    printf("Roll No: %d\n",
           student1.rollNo);

    printf("Name: %s\n",
           student1.name);

    printf("Date of Birth: %d-%d-%d\n",
           student1.birthDate.day,
           student1.birthDate.month,
           student1.birthDate.year);

    return 0;
}

Output

Roll No: 101
Name: Rahul
Date of Birth: 15-8-2005

13.22 Structures and Functions

Structures can be passed to functions just like other values in C.

A structure can be:

  • Passed to a function by value.
  • Passed to a function using a pointer.
  • Returned from a function.

13.23 Passing Structure to a Function by Value

When a structure is passed by value, the function receives a copy of the structure. 

#include <stdio.h>

struct Student
{
    int rollNo;
    float marks;
};

void display(struct Student s)
{
    printf("Roll No: %d\n", s.rollNo);
    printf("Marks: %.2f\n", s.marks);
}

int main()
{
    struct Student student1 =
    {
        101,
        85.5
    };

    display(student1);

    return 0;
}

Output

Roll No: 101
Marks: 85.50
Changes made to the parameter inside the function do not modify the original structure object when it is passed by value.

13.24 Passing Structure Using a Pointer

A pointer to a structure can be passed to a function when the function needs to work with the original structure object. 

#include <stdio.h>

struct Student
{
    int rollNo;
    float marks;
};

void updateMarks(struct Student *s)
{
    s->marks = 90.0;
}

int main()
{
    struct Student student1 =
    {
        101,
        85.5
    };

    updateMarks(&student1);

    printf("Roll No: %d\n",
           student1.rollNo);

    printf("Marks: %.2f\n",
           student1.marks);

    return 0;
}

Output

Roll No: 101
Marks: 90.00

13.25 Arrow Operator (->)

When a pointer to a structure is used to access a structure member, the arrow operator -> is used.

Example

struct Student student1;

struct Student *ptr;

ptr = &student1;

ptr->rollNo = 101;

ptr->marks = 85.5;

The following two expressions are equivalent: 

ptr->marks

(*ptr).marks
Easy rule: Use . with a structure variable.
Use -> with a pointer to a structure.

13.26 Structure Pointer Example

#include <stdio.h>

struct Employee
{
    int id;
    float salary;
};

int main()
{
    struct Employee employee =
    {
        101,
        45000.0
    };

    struct Employee *ptr = &employee;

    printf("Employee ID: %d\n",
           ptr->id);

    printf("Salary: %.2f\n",
           ptr->salary);

    return 0;
}

Output

Employee ID: 101
Salary: 45000.00

13.27 Returning a Structure from a Function

A function can return a structure value.

Example

#include <stdio.h>

struct Student
{
    int rollNo;
    float marks;
};

struct Student createStudent()
{
    struct Student s =
    {
        101,
        88.5
    };

    return s;
}

int main()
{
    struct Student student1;

    student1 = createStudent();

    printf("Roll No: %d\n",
           student1.rollNo);

    printf("Marks: %.2f\n",
           student1.marks);

    return 0;
}

Output

Roll No: 101
Marks: 88.50

13.28 typedef with Structures

The typedef keyword can be used to create a convenient alias for a structure type.

Without typedef

struct Student student1;

With typedef

typedef struct
{
    int rollNo;
    char name[50];
    float marks;
} Student;

Student student1;

Using typedef avoids writing struct Student repeatedly.

13.29 typedef Structure Example

#include <stdio.h>

typedef struct
{
    int id;
    float salary;
} Employee;

int main()
{
    Employee employee1 =
    {
        101,
        45000.0
    };

    printf("ID = %d\n",
           employee1.id);

    printf("Salary = %.2f\n",
           employee1.salary);

    return 0;
}

Output

ID = 101
Salary = 45000.00

13.30 Structure Assignment

Structure objects of the same structure type can be assigned to each other using the assignment operator. 

struct Student student1 =
{
    101,
    "Rahul",
    85.5
};

struct Student student2;

student2 = student1;

After the assignment, the members of student2 have the corresponding values from student1.

Structure assignment copies the structure value. For structures containing pointers, the pointer values are copied; the dynamically allocated objects they point to are not automatically duplicated.

13.31 Comparing Structures

C does not provide a general built-in == operator for comparing two structure objects.

Structure members should be compared individually when logical comparison is required. 

if (student1.rollNo == student2.rollNo)
{
    printf("Same roll number");
}
Do not use student1 == student2 for ordinary structure comparison in C. Compare the relevant members individually.

13.32 Structure Containing Character Array

A structure can contain a character array as a member. Character arrays are commonly used to store names, addresses, department names and other text information.

Example

#include <stdio.h>

struct Employee

int main()

Output

Name: Ravi
Department: Computer Science

13.33 Structure Containing an Array

A structure can contain an array as one of its members. This is useful when a record needs to store multiple values of the same type.

Example

#include <stdio.h>

struct Student
{
    int rollNo;
    char name[50];
    int marks[3];
};

int main()
{
    struct Student student =
    {
        101,
        "Ravi",
        {80, 85, 90}
    };

    printf("Roll No: %d\n", student.rollNo);
    printf("Name: %s\n", student.name);

    printf("Marks:\n");

    for (int i = 0; i < 3; i++)
    {
        printf("%d ", student.marks[i]);
    }

    return 0;
}

Output

Roll No: 101
Name: Ravi
Marks:
80 85 90

13.34 Structure Containing Pointer

A structure can contain pointer members. Such pointers can store addresses of variables or dynamically allocated memory.

Example

#include <stdio.h>

struct Student
{
    int rollNo;
    int *marks;
};

int main()
{
    int marks = 85;

    struct Student student =
    {
        101,
        &marks
    };

    printf("Roll No: %d\n",
           student.rollNo);

    printf("Marks: %d\n",
           *student.marks);

    return 0;
}

Output

Roll No: 101
Marks: 85
A pointer member stores an address. The value at that address can be accessed using the dereference operator *.

13.35 Self-Referential Structure

A structure that contains a pointer to another object of the same structure type is called a self-referential structure.

Self-referential structures are commonly used to create dynamic data structures such as linked lists, trees and graphs.

Example

struct Node
{
    int data;
    struct Node *next;
};

Here, next is a pointer that can point to another struct Node.

13.36 Self-Referential Structure Example

#include <stdio.h>

struct Node
{
    int data;
    struct Node *next;
};

int main()
{
    struct Node first;

    first.data = 10;
    first.next = NULL;

    printf("Data = %d\n", first.data);

    return 0;
}

Output

Data = 10

The NULL pointer indicates that the node does not currently point to another node.

13.37 Structure Pointer and Dynamic Memory

Structure pointers can be used with dynamic memory allocation functions such as malloc() and free().

Example

#include <stdio.h>
#include <stdlib.h>

struct Student
{
    int rollNo;
    float marks;
};

int main()
{
    struct Student *student;

    student = malloc(sizeof(struct Student));

    if (student == NULL)
    {
        printf("Memory allocation failed");
        return 1;
    }

    student->rollNo = 101;
    student->marks = 87.5;

    printf("Roll No: %d\n",
           student->rollNo);

    printf("Marks: %.2f\n",
           student->marks);

    free(student);

    return 0;
}

Output

Roll No: 101
Marks: 87.50
Memory obtained using malloc() should be released using free() when it is no longer needed.

13.38 Structure Padding

Structure members may require alignment in memory. As a result, the compiler can insert unused bytes between members or at the end of a structure. This is called structure padding.

Example

struct Example
{
    char a;
    int b;
};

Although the members occupy their own storage, the total size of the structure may be greater than the simple sum of the sizes of its members because of alignment and padding.

Checking Structure Size

#include <stdio.h>

struct Example
{
    char a;
    int b;
};

int main()
{
    printf("Size = %zu bytes",
           sizeof(struct Example));

    return 0;
}

The exact result can depend on the compiler, target architecture and alignment rules.

13.39 Structure Alignment

Structure alignment refers to how structure members are arranged in memory according to the alignment requirements of their types.

Proper alignment can allow the processor to access data efficiently.

Important: Do not assume that a structure always occupies exactly the sum of the sizes of all its members.

13.42 Array of Structures with Sorting

Arrays of structures can be sorted according to one of their members. For example, student records can be sorted according to marks.

Example

#include <stdio.h>

struct Student
{
    int rollNo;
    char name[50];
    float marks;
};

int main()
{
    struct Student students[3] =
    {
        {101, "Ravi", 72.5},
        {102, "Anil", 91.0},
        {103, "Kiran", 84.5}
    };

    struct Student temp;

    for (int i = 0; i < 3 - 1; i++)
    {
        for (int j = i + 1; j < 3; j++)
        {
            if (students[i].marks < students[j].marks)
            {
                temp = students[i];
                students[i] = students[j];
                students[j] = temp;
            }
        }
    }

    printf("Students sorted by marks:\n\n");

    for (int i = 0; i < 3; i++)
    {
        printf("Roll No: %d\n",
               students[i].rollNo);

        printf("Name: %s\n",
               students[i].name);

        printf("Marks: %.2f\n\n",
               students[i].marks);
    }

    return 0;
}

Output

Students sorted by marks:

Roll No: 102
Name: Anil
Marks: 91.00

Roll No: 103
Name: Kiran
Marks: 84.50

Roll No: 101
Name: Ravi
Marks: 72.50

13.43 Searching in an Array of Structures

Structures can be searched using a member such as roll number, employee ID or book ID.

Example

#include <stdio.h>

struct Student
{
    int rollNo;
    char name[50];
    float marks;
};

int main()
{
    struct Student students[3] =
    {
        {101, "Ravi", 80.0},
        {102, "Anil", 85.0},
        {103, "Kiran", 90.0}
    };

    int searchRoll;
    int found = 0;

    printf("Enter roll number: ");
    scanf("%d", &searchRoll);

    for (int i = 0; i < 3; i++)
    {
        if (students[i].rollNo == searchRoll)
        {
            printf("Student Found\n");
            printf("Name: %s\n",
                   students[i].name);
            printf("Marks: %.2f\n",
                   students[i].marks);

            found = 1;
            break;
        }
    }

    if (!found)
    {
        printf("Student not found");
    }

    return 0;
}

13.44 Advantages of Structures

  • Structures group related data into a single unit.
  • They make programs easier to organize.
  • They are useful for representing real-world records.
  • Different data types can be stored in one structure.
  • Structures can be used with arrays and pointers.
  • Structures can be passed to and returned from functions.
  • They are useful for implementing complex data structures.

13.45 Limitations of Structures

  • Structure objects may require extra memory because of padding and alignment.
  • C does not provide general built-in equality comparison for structures.
  • Care is required when structures contain pointer members.
  • Large structures can be expensive to copy when passed by value.
  • Complex nested structures can become difficult to understand if poorly designed.

13.50 Program: Student Result Using Structure

A structure can store student information and marks. Calculations can then be performed using structure members. 

#include <stdio.h>

struct Student
{
    int rollNo;
    char name[50];
    int marks1;
    int marks2;
    int marks3;
    int total;
    float average;
};

int main()
{
    struct Student student;

    printf("Enter roll number: ");
    scanf("%d", &student.rollNo);

    printf("Enter name: ");
    scanf("%49s", student.name);

    printf("Enter three marks: ");
    scanf("%d %d %d",
          &student.marks1,
          &student.marks2,
          &student.marks3);

    student.total =
        student.marks1 +
        student.marks2 +
        student.marks3;

    student.average =
        student.total / 3.0;

    printf("\nStudent Result\n");
    printf("Roll No: %d\n", student.rollNo);
    printf("Name: %s\n", student.name);
    printf("Total: %d\n", student.total);
    printf("Average: %.2f\n", student.average);

    return 0;
}

Example Output

Enter roll number: 101
Enter name: Ravi
Enter three marks: 80 85 90

Student Result
Roll No: 101
Name: Ravi
Total: 255
Average: 85.00

13.51 Program: Array of Student Structures

13.52 Program: Find the Student with Highest Marks

#include <stdio.h>

struct Student
{
    int rollNo;
    char name[50];
    float marks;
};

int main()
{
    struct Student students[3] =
    {
        {101, "Ravi", 82.5},
        {102, "Anil", 94.0},
        {103, "Kiran", 88.5}
    };

           students[highest].name);

    printf("Marks: %.2f\n",
           students[highest].marks);

    return 0;
}

13.53 Passing a Structure Pointer to a Function

A pointer to a structure can be passed to a function. This allows the function to access or modify the original structure object. 

#include <stdio.h>

struct Student
{
    int rollNo;
    float marks;
};

void updateMarks(struct Student *s)
{
    s->marks = s->marks + 5;
}

int main()
{
    struct Student student =
    {
        101,
        80.0
    };

    printf("Before update: %.2f\n",
           student.marks);

    updateMarks(&student);

    printf("After update: %.2f\n",
           student.marks);

    return 0;
}

Output

Before update: 80.00
After update: 85.00
When using a structure pointer, use the -> operator to access members.

13.54 Returning a Structure from a Function

A function in C can return a structure value. 

#include <stdio.h>

struct Point
{
    int x;
    int y;
};

struct Point createPoint()
{
    struct Point p;

    p.x = 10;
    p.y = 20;

    return p;
}

int main()
{
    struct Point point;

    point = createPoint();

    printf("X = %d\n", point.x);
    printf("Y = %d\n", point.y);

    return 0;
}

Output

X = 10
Y = 20

13.55 Nested Structures

A structure can contain another structure as one of its members. This is called a nested structure.

Example

#include <stdio.h>

struct Date
{
    int day;
    int month;
    int year;
};

struct Student
{
    int rollNo;
    char name[50];
    struct Date dob;
};

int main()
{
    struct Student student =
    {
        101,
        "Ravi",
        {15, 8, 2005}
    };

    printf("Roll No: %d\n",
           student.rollNo);

    printf("Name: %s\n",
           student.name);

    printf("Date of Birth: %d-%d-%d\n",
           student.dob.day,
           student.dob.month,
           student.dob.year);

    return 0;
}

Output

Roll No: 101
Name: Ravi
Date of Birth: 15-8-2005

13.56 Real-World Applications of Structures

Structures are widely used in real-world software because they allow related information to be represented as a single record.

  • Student Management: Store roll number, name, marks and course details.
  • Banking Systems: Store account number, customer name and balance.
  • Library Systems: Store book ID, title, author and availability.
  • Employee Management: Store employee ID, name, department and salary.
  • Hospital Systems: Store patient ID, name, age and other record information.
  • Inventory Systems: Store product ID, name, quantity and price.
  • Data Structures: Structures are used to build linked lists, trees and other data structures.

13.57 Common Errors in Structures

1. Forgetting the semicolon

struct Student
{
    int rollNo;
}   /* Error */

A semicolon is required after the closing brace. 

struct Student
{
    int rollNo;
};

2. Using the wrong member operator

Use . with a structure object. 

student.rollNo

Use -> with a pointer to a structure. 

studentPtr->rollNo

3. Accessing a member that does not exist

struct Student
{
    int rollNo;
};

student.name = "Ravi";

The member name has not been declared in the structure.

4. Incorrect initialization

Structure initializer values should correspond to the declared members in the appropriate order.

5. Incorrect pointer usage

Dereferencing an invalid structure pointer can cause undefined behavior.

13.58 Best Practices for Using Structures

  • Give structures meaningful names.
  • Give structure members clear and descriptive names.
  • Keep related information together.
  • Use arrays of structures for multiple records.
  • Use structure pointers when appropriate for large structures or modification of existing objects.
  • Use const when a function should not modify a structure passed through a pointer.
  • Initialize structure variables before using their members.
  • Be careful when structures contain pointers.
  • Free dynamically allocated memory when it is no longer required.
Best Practice: Design a structure so that all its members represent logically related information.

13.59 Structure Initialization Methods

There are several ways to initialize structure objects.

Method 1: Initialization in Declaration

struct Student
{
    int rollNo;
    float marks;
};

struct Student s1 = {101, 85.5};

Method 2: Designated Initialization

struct Student s2 =
{
    .rollNo = 102,
    .marks = 90.0
};

Method 3: Assigning Members Individually

struct Student s3;

s3.rollNo = 103;
s3.marks = 88.5;

Designated initialization can make code clearer because each value is explicitly associated with a member name.

13.60 Structure and const

The const keyword can be used when a structure should not be modified through a particular pointer. 

#include <stdio.h>

struct Student
{
    int rollNo;
    float marks;
};

void display(const struct Student *s)
{
    printf("Roll No: %d\n", s->rollNo);
    printf("Marks: %.2f\n", s->marks);
}

int main()
{
    struct Student student =
    {
        101,
        90.0
    };

    display(&student);

    return 0;
}

Using const helps communicate that the function only needs to read the structure data.

13.63 Summary

A structure is an important user-defined data type in C. It allows related data items of different data types to be grouped together under one name.

Structures are especially useful for representing real-world entities such as students, employees, books, customers, products and bank accounts.

  • Structures are declared using the struct keyword.
  • Structure members can have different data types.
  • The dot operator . is used with structure variables.
  • The arrow operator -> is used with pointers to structures.
  • Arrays of structures can store multiple records.
  • Structures can contain arrays, pointers and other structures.
  • A self-referential structure can contain a pointer to another object of the same structure type.
  • Structures can be passed to functions by value or through pointers.
  • Functions can return structure values.
  • The typedef keyword can provide a convenient name for a structure type.
  • Structure size can include padding and alignment bytes.
Easy Definition for Exams: A structure is a user-defined data type in C that groups related variables of different data types under a single name.
