Chapter 9: Functions in C

Learn how functions divide a C program into smaller, reusable and organized blocks of code.

Introduction to Functions

A function is a named block of statements that performs a specific task.

Functions help divide a large program into smaller, manageable and reusable parts.

Instead of writing the same code repeatedly, we can place that code inside a function and call the function whenever it is required.

Simple Example

#include <stdio.h>

void message()
{
    printf("Welcome to ALLIED");
}

int main()
{
    message();

    return 0;
}

Output

Welcome to ALLIED
Simple Definition: A function is a reusable block of code designed to perform a particular task.

Why Are Functions Needed?

Functions are needed to make programs easier to develop, understand, test and maintain.

  • To reduce code repetition.
  • To divide a large program into smaller parts.
  • To improve program readability.
  • To make code reusable.
  • To simplify debugging.
  • To make maintenance easier.
  • To support modular programming.

Advantages of Functions

  • Reusability: A function can be called multiple times.
  • Modularity: Large programs can be divided into smaller modules.
  • Readability: Functions make programs easier to understand.
  • Debugging: Individual functions can be tested separately.
  • Maintenance: Changes can be made in one function without rewriting the entire program.

Basic Structure of a Function

return_type function_name(parameters)
{
    statements;

    return value;
}
Part Description
Return type Specifies the type of value returned by the function.
Function name The name used to identify and call the function.
Parameters Values received by the function.
Function body Contains the statements that perform the task.
Return statement Sends a value back to the calling function.

Function Working

Library Functions

Library functions are predefined functions provided by the C standard library.

These functions can be used by including the appropriate header file.

Examples

Function Header File Purpose
printf() <stdio.h> Displays output.
scanf() <stdio.h> Reads input.
strlen() <string.h> Finds string length.
sqrt() <math.h> Calculates square root.
pow() <math.h> Calculates powers.

User-Defined Functions

A user-defined function is a function created by the programmer to perform a specific task.

Example

#include <stdio.h>

void greet()
{
    printf("Hello from ALLIED");
}

int main()
{
    greet();

    return 0;
}

Output

Hello from ALLIED

Function Declaration

A function declaration, also called a function prototype, tells the compiler about the function before it is used.

Syntax

return_type function_name(parameter_list);

Example

int add(int, int);

This tells the compiler that a function named add exists, accepts two integer arguments, and returns an integer.

Important: A function prototype normally ends with a semicolon.

Function Definition

A function definition contains the actual statements that perform the required task.

Example

int add(int a, int b)
{
    return a + b;
}

Here, a and b are parameters and the function returns their sum.

Function Calling

A function is executed when it is called.

Example

#include <stdio.h>

void display()
{
    printf("Welcome to C Programming");
}

int main()
{
    display();

    return 0;
}

Output

Welcome to C Programming

In this program, display() is called from the main() function.

Arguments and Parameters

Parameters are variables declared in the function definition. Arguments are the actual values passed when the function is called.

Example

#include <stdio.h>

void add(int a, int b)
{
    printf("Sum = %d", a + b);
}

int main()
{
    add(10, 20);

    return 0;
}

Output

Sum = 30
Term Example
Parameters int a, int b
Arguments 10, 20

Return Value

A function can return a value to the calling function using the return statement.

Example

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int main()
{
    int result;

    result = add(10, 20);

    printf("Sum = %d", result);

    return 0;
}

Output

Sum = 30

Function Categories Based on Arguments and Return Value

User-defined functions can commonly be classified into four categories based on whether they accept arguments and whether they return a value.

Type 2 Yes No

Function Type 1: No Arguments and No Return Value

In this type of function, no values are passed to the function and the function does not return any value.

Example

#include <stdio.h>

void display()
{
    printf("Hello, World!");
}

int main()
{
    display();

    return 0;
}

Output

Hello, World!

Function Type 2: Arguments and No Return Value

In this type, arguments are passed to the function, but the function does not return a value.

Example

#include <stdio.h>

void add(int a, int b)
{
    printf("Sum = %d", a + b);
}

int main()
{
    add(10, 20);

    return 0;
}

Output

Sum = 30

Function Type 3: No Arguments and Return Value

In this type, the function does not receive arguments but returns a value to the calling function.

Example

#include <stdio.h>

int getNumber()
{
    return 100;
}

int main()
{
    int value;

    value = getNumber();

    printf("Value = %d", value);

    return 0;
}

Output

Value = 100

Function Type 4: Arguments and Return Value

In this type, arguments are passed to the function and the function returns a value.

Example

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int main()
{
    int result;

    result = add(15, 25);

    printf("Sum = %d", result);

    return 0;
}

Output

Sum = 40

Call by Value

In C, arguments are passed to functions by value by default. This means that the function receives copies of the values supplied by the caller.

Changes made to the parameters inside the function do not change the original variables in the calling function.

Example

#include <stdio.h>

void change(int x)
{
    x = 100;
}

int main()
{
    int number = 10;

    change(number);

    printf("Number = %d", number);

    return 0;
}

Output

Number = 10
Important: The function changes its local copy of the value, not the original variable in main().

Call by Value Flow

main() | | number = 10 | v change(number) | v x = 10 (copy) | v x = 100 | v Return to main() | v number = 10

Function Scope and Local Variables

A variable declared inside a function is generally local to that function and cannot be directly accessed from another function.

Example

#include <stdio.h>

void display()
{
    int number = 50;

    printf("Number = %d", number);
}

int main()
{
    display();

    return 0;
}

Output

Number = 50
A local variable exists only within its scope. Do not try to use a local variable outside the function where it is declared.

Multiple Function Calls

A function can be called multiple times from the same program.

Example

#include <stdio.h>

void message()
{
    printf("Hello\n");
}

int main()
{
    message();
    message();
    message();

    return 0;
}

Output

Hello
Hello
Hello

Nested Function Calls

One function can call another function. This allows a program to divide a complex task into smaller tasks.

Example

#include <stdio.h>

void second()
{
    printf("Second function\n");
}

void first()
{
    printf("First function\n");
    second();
}

int main()
{
    first();

    return 0;
}

Output

First function
Second function

Recursion

Recursion is a technique in which a function calls itself to solve a problem.

A recursive function must have a base condition that stops further recursive calls.

Basic Structure

return_type function()
{
    if (condition)
    {
        return value;
    }

    function();
}
Without a proper base condition, recursion can continue indefinitely and may cause stack overflow.

Recursive Function Example

#include <stdio.h>

void count(int n)
{
    if (n == 0)
    {
        return;
    }

    printf("%d\n", n);

    count(n - 1);
}

int main()
{
    count(5);

    return 0;
}

Output

5
4
3
2
1

Factorial Using Recursion

#include <stdio.h>

int factorial(int n)
{
    if (n == 0 || n == 1)
    {
        return 1;
    }

    return n * factorial(n - 1);
}

int main()
{
    int n = 5;

    printf("Factorial = %d", factorial(n));

    return 0;
}

Output

Factorial = 120

Program: Check Prime Number Using Function

#include <stdio.h>

int isPrime(int number)
{
    if (number < 2)
    {
        return 0;
    }

    for (int i = 2; i * i <= number; i++)
    {
        if (number % i == 0)
        {
            return 0;
        }
    }

    return 1;
}

int main()
{
    int number = 17;

    if (isPrime(number))
    {
        printf("Prime number");
    }
    else
    {
        printf("Not a prime number");
    }

    return 0;
}

Output

Prime number

Program: Factorial Using Function

#include <stdio.h>

int factorial(int n)
{
    int fact = 1;

    for (int i = 1; i <= n; i++)
    {
        fact = fact * i;
    }

    return fact;
}

int main()
{
    int number = 5;

    printf("Factorial = %d", factorial(number));

    return 0;
}

Output

Factorial = 120

Program: Fibonacci Using Function

#include <stdio.h>

void fibonacci(int n)
{
    int first = 0;
    int second = 1;
    int next;

    for (int i = 1; i <= n; i++)
    {
        printf("%d ", first);

        next = first + second;
        first = second;
        second = next;
    }
}

int main()
{
    fibonacci(8);

    return 0;
}

Output

0 1 1 2 3 5 8 13

Program: Swap Two Numbers Using Function

In C, passing ordinary variables to a function passes their values. Therefore, changing the parameters alone does not change the original variables. 

#include <stdio.h>

void swap(int a, int b)
{
    int temp;

    temp = a;
    a = b;
    b = temp;

    printf("Inside function:\n");
    printf("a = %d\n", a);
    printf("b = %d\n", b);
}

int main()
{
    int x = 10;
    int y = 20;

    swap(x, y);

    printf("Inside main:\n");
    printf("x = %d\n", x);
    printf("y = %d\n", y);

    return 0;
}

Output

Inside function:
a = 20
b = 10
Inside main:
x = 10
y = 20

Function Prototype Example

A function prototype can be written before the main function when the function definition appears later in the program. 

#include <stdio.h>

int square(int);

int main()
{
    int result;

    result = square(6);

    printf("Square = %d", result);

    return 0;
}

int square(int number)
{
    return number * number;
}

Output

Square = 36

Advantages of Using Functions

  • Code Reusability: The same function can be called many times.
  • Modularity: A large program can be divided into smaller modules.
  • Easy Debugging: Errors can be isolated within individual functions.
  • Easy Maintenance: Changes can be made in a particular function.
  • Better Readability: Functions make program logic easier to understand.
  • Reduced Repetition: Repeated code can be placed inside a function.

Disadvantages or Limitations of Functions

  • Excessive use of small functions can make a program difficult to follow.
  • Function calls introduce some execution overhead.
  • Incorrect parameter handling can produce unexpected results.
  • Recursive functions can consume significant stack memory.
  • Poorly designed functions can make program structure unnecessarily complicated.

Common Errors in Functions

  • Forgetting to declare a function when required.
  • Using an incorrect return type.
  • Passing the wrong number of arguments.
  • Passing arguments of inappropriate types.
  • Forgetting the return statement when a value is required.
  • Calling a function with the wrong name.
  • Using a local variable outside its scope.
  • Forgetting the semicolon in a function prototype.
  • Creating recursion without a proper base condition.

Incorrect Example

int add(int a, int b)
{
    printf("%d", a + b);
}

int main()
{
    int result;

    result = add(10, 20);

    return 0;
}

The function is declared to return an int, but it does not return an integer value.

Correct Example

int add(int a, int b)
{
    return a + b;
}

Best Practices for Functions

  • Give functions meaningful and descriptive names.
  • Keep each function focused on one specific task.
  • Use function prototypes when necessary.
  • Use appropriate parameter and return types.
  • Avoid unnecessary global variables.
  • Keep functions reasonably small and readable.
  • Use comments when the purpose of a function is not obvious.
  • Always provide a proper base condition for recursive functions.
  • Test each function with different inputs.
Programming Tip: A good function should normally have one clear responsibility. This makes the program easier to understand, test and maintain.

Chapter Summary

Functions are one of the most important concepts in C programming. They allow a large program to be divided into smaller and reusable blocks.

  • A function performs a specific task.
  • Functions improve code organization and reusability.
  • C provides library functions and allows programmers to create user-defined functions.
  • A function may have parameters and may return a value.
  • A function prototype declares a function before its use when necessary.
  • Function arguments are passed by value by default in C.
  • Recursion occurs when a function calls itself.
  • Recursive functions require a proper base condition.
  • Local variables are generally accessible only within their scope.
Key Point: Functions make programs modular, reusable, readable and easier to test and maintain.
